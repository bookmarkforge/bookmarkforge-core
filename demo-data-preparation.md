   ```
   BookmarkForge usa cifrado AES-256-GCM con derivación de clave Argon2id.
   Esto proporciona protección robusta contra ataques de fuerza bruta.
   Los datos nunca salen del dispositivo del usuario.
   ```


### Escenarios de Demostración

#### Escenario 1: Creación de Vault
1. Abrir aplicación
2. Click en "Create Vault"
3. Ingresar contraseña de ejemplo
4. Guardar frase de recuperación
5. Completar setup

#### Escenario 2: Agregar Contenido
1. Navegar a Bookmarks
2. Agregar 2-3 bookmarks de ejemplo
3. Agregar notas de ejemplo
4. Organizar con etiquetas

#### Escenario 3: Búsqueda
1. Usar la barra de búsqueda
2. Buscar "security"
3. Buscar "AI"
4. Demostrar filtros

#### Escenario 4: IA Integration
1. Ir a Settings → AI Providers
2. Configurar WebLLM (IA local)
3. Abrir un bookmark
4. Click en "Summarize with AI"
5. Mostrar resumen generado

#### Escenario 5: Backup
1. Ir a Settings → Backup
2. Click en "Create Backup"
3. Guardar archivo .bmf
4. Demostrar proceso de restore

#### Escenario 6: Sincronización
1. Ir a Settings → Sync
2. Mostrar opciones P2P
3. Explicar WebRTC
4. Demostrar código QR (si disponible)

### Tips para la Demo

1. **Preparación Previa**
   - Ten todos los datos listos en un archivo separado
   - Practica el flujo 2-3 veces antes de grabar
   - Asegúrate de que la aplicación responda rápido

2. **Durante la Grabación**
   - Habla claro y a ritmo moderado
   - Pausa 1-2 segundos después de cada acción importante
   - Usa el cursor de forma deliberada
   - Evita movimientos bruscos

3. **Manejo de Errores**
   - Si algo falla, continúa con el siguiente paso
   - No te disculpes en el video
   - Puedes editar errores en post-producción
