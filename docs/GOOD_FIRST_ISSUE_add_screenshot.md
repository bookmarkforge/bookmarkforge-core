# [GOOD FIRST ISSUE] Add a screenshot to README

This is a good first issue for new contributors.

## Task
Add a screenshot of the BookmarkForge UI to the README.md file.

## Steps
1. Take a screenshot of the BookmarkForge app running locally
2. Save it to `docs/images/` directory
3. Add it to the README.md with:

```markdown
![BookmarkForge UI](docs/images/screenshot.png)
```

## Benefit
Makes the repository more visual and attractive to new visitors.

## Difficulty
Easy
