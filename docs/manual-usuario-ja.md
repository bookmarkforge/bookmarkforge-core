# ユーザーマニュアル — BookmarkForge v1

**バージョン:** 1.0.0 · **最終更新:** 2026年9月 · **ライセンス:** AGPL-3.0

## 1. 概要

BookmarkForgeは、ブックマーク、メモ、ドキュメントを整理する個人向けの知識アプリです。保管庫の内容はブラウザのローカルストレージに保存され、BookmarkForgeへ送信されません。外部AIプロバイダーを使う場合、その機能に明示的に送信したデータだけがプロバイダーへ渡ります。

保管庫はAES-GCMで端末上に暗号化され、Argon2idでマスターパスワードから鍵を作ります。パスワードは復元できないため、安全に保管してください。

## 2. はじめに

1. [bookmarkforge.com](https://bookmarkforge.com)を開きます。
2. ブラウザが対応していればPWAとしてインストールします。
3. 12文字以上のマスターパスワードを作成します。
4. 24個のリカバリーフレーズを安全な場所に保存します。
5. 暗号化された`.bmf`バックアップを定期的に書き出します。

初回読み込み後はオフラインでも利用できます。ブックマークレットやブラウザー拡張機能から、開いているページをすぐに保存できます。

## 3. ブックマークと検索

- ページのURL、タイトル、日付、タグを保存できます。
- キーワードだけでなく意味でも探せるスマート検索はFreeに含まれます。
- Freeは**1,000件のブックマーク**までで、デバイス数の上限はありません。ただしProの同期を使わない場合、各デバイスの保管庫は別々です。
- 1,000件に達してもデータは削除されません。閲覧、検索、エクスポートは続けて使え、新しい保存だけが一時停止します。
- Proでは上限がなくなり、最大3台をP2Pで同期できます。

## 4. Pocketからのインポート

**設定 → インポート**を開き、`ril_export.html`またはPocketから書き出したCSVを選びます。形式は自動判定され、保存前にリンク数、日付、タグのプレビューが表示されます。

既読、未読、アーカイブの状態も保持されます。Freeの上限に達した場合は、何件を取り込めたかと上限に達したことを結果に明示します。残りの項目を「スキップ」として水増しすることはありません。

## 5. メモ、AI、同期

エディターでは構造化されたメモ、表、ドキュメント間のリンクを作成できます。自分のAPIキーを使うAIでは、プロバイダーの規約とプライバシー条件が適用され、料金もプロバイダーへ直接支払います。

WebLLM/OllamaによるローカルAI、データに基づくRAGチャット、フラッシュカード、P2P同期はPro機能です。P2P同期には同じWi-Fiまたは設定済みのシグナリングサービスが必要になる場合があります。

## 6. バックアップと復元

- 移行や重要な操作の前に`.bmf`バックアップを作成します。
- 複数の場所にコピーを保管します。
- 復元にはマスターパスワードが必要です。
- パスワードとリカバリーフレーズ、利用可能なバックアップをすべて失うと、サポートでも復元できません。

## 7. FreeとPro

| 機能 | Free | Pro |
|---|---|---|
| ブックマーク | 1,000件 | 無制限 |
| デバイス | 上限なし、保管庫は別々 | 最大3台、P2P同期 |
| スマート検索 | 含まれる | 含まれる |
| 自分のキーによるAI | 利用可 | 利用可 |
| ローカルAIとRAGチャット | 利用不可 | 利用可 |
| JSON/HTMLと`.bmf`エクスポート | 利用可 | 利用可 |
| 料金 | 無料 | v1の買い切りライセンス |

**設定 → Pro**からWhopのチェックアウトを開いて有効化します。ライセンス確認のためサービスへ接続しますが、保管庫は送信されません。

## 8. トラブルシューティング

- **アプリが開かない:** ブラウザーを更新し、空き容量を確認し、問題のある拡張機能を一時停止します。
- **保存できない:** Freeの件数を確認します。1,000件ならエクスポート、削除、またはProへのアップグレードを行います。
- **同期できない:** ネットワーク、ファイアウォール、両デバイスのIDを確認します。
- **ライセンスを有効化できない:** 接続を確認し、パスワードやリカバリーフレーズではなくエラーコードだけをサポートへ送ります。

## 9. プライバシーとサポート

保管庫の内容は標準では端末内に残ります。決済、ライセンス、リモートAI、P2Pシグナリング、同意したエラー報告などの任意サービスは、それぞれ必要な技術データだけを処理します。

サポート: `bookmarkforge@proton.me`。サポートがパスワードやリカバリーフレーズを尋ねることはありません。
