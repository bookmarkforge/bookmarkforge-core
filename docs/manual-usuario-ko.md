# 사용자 매뉴얼 — BookmarkForge v1

**버전:** 1.0.0 · **최종 업데이트:** 2026년 9월 · **라이선스:** MIT

## 시작하기

BookmarkForge는 북마크, 메모, 문서를 저장하고 개인 지식을 정리하는 앱입니다. 보관함 내용은 브라우저의 로컬 저장소에 남으며 BookmarkForge로 전송되지 않습니다. 외부 AI 제공업체에는 해당 기능으로 명시적으로 보낸 데이터만 전달됩니다.

보관함은 AES-GCM으로 로컬 암호화되고 Argon2id가 기본 비밀번호에서 키를 만듭니다. 지원팀은 잃어버린 비밀번호를 복구할 수 없습니다.

1. [bookmarkforgeapp.com](https://bookmarkforgeapp.com)을 엽니다.
2. 12자 이상의 기본 비밀번호를 만듭니다.
3. 24개의 복구 단어를 안전하게 보관합니다.
4. 암호화된 `.bmf` 백업을 정기적으로 내보냅니다.

## 북마크와 검색

Free에는 단어와 의미로 찾는 스마트 검색이 포함됩니다. Free는 **2,500개 북마크**를 지원하며 기기 수 제한이 없습니다. Pro 동기화를 사용하지 않으면 각 기기에 별도 보관함이 있습니다. 2,500개에 도달해도 데이터는 삭제되지 않습니다. 읽기, 검색, 내보내기는 계속되고 새 저장만 일시 중지됩니다. Pro는 제한을 없애고 최대 5대의 기기를 P2P로 동기화합니다.

## Pocket에서 가져오기

**설정 → 가져오기**에서 `ril_export.html` 또는 Pocket CSV를 선택합니다. 저장 전에 링크, 날짜, 태그 미리보기가 표시됩니다. 읽음, 읽지 않음, 보관 상태가 유지됩니다. Free 한도에 도달하면 가져온 개수와 한도 도달 사실을 결과에 표시하며 나머지를 건너뜀으로 잘못 계산하지 않습니다.

## 메모, AI, 동기화

편집기는 구조화된 메모, 표, 문서 간 링크를 지원합니다. WebLLM/Ollama 로컬 AI, RAG 채팅, 플래시카드, P2P 동기화는 Pro 기능입니다. 개인 API 키를 사용하면 해당 제공업체의 조건이 적용됩니다.

## 백업과 지원

여러 위치에 `.bmf` 사본을 보관하세요. 복원에는 기본 비밀번호가 필요합니다. 저장이 거부되면 Free 카운터를 확인하고, 동기화가 실패하면 네트워크·방화벽·기기 ID를 확인하세요. 지원팀에 비밀번호나 복구 단어를 보내지 마세요.

지원: `bookmarkforge@proton.me`.
