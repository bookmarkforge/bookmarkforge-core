# คู่มือผู้ใช้ — BookmarkForge v1

**เวอร์ชัน:** 1.0.0 · **อัปเดตล่าสุด:** กันยายน 2026 · **ใบอนุญาต:** MIT

## เริ่มต้นใช้งาน

BookmarkForge ใช้บันทึกบุ๊กมาร์ก โน้ต และเอกสารเพื่อจัดระเบียบความรู้ส่วนตัว เนื้อหาในคลังจะอยู่ในพื้นที่จัดเก็บภายในเบราว์เซอร์และจะไม่ถูกส่งไปยัง BookmarkForge ผู้ให้บริการ AI ภายนอกจะได้รับเฉพาะข้อมูลที่คุณส่งให้ฟีเจอร์นั้นโดยตั้งใจ

คลังถูกเข้ารหัสในอุปกรณ์ด้วย AES-GCM และ Argon2id ใช้สร้างคีย์จากรหัสผ่านหลัก ฝ่ายสนับสนุนไม่สามารถกู้รหัสผ่านที่ลืมได้

1. เปิด [bookmarkforgeapp.com](https://bookmarkforgeapp.com)
2. ตั้งรหัสผ่านหลักอย่างน้อย 12 ตัวอักษร
3. เก็บคำกู้คืน 24 คำไว้ในที่ปลอดภัย
4. ส่งออกข้อมูลสำรอง `.bmf` ที่เข้ารหัสเป็นประจำ

## บุ๊กมาร์กและการค้นหา

Free มีการค้นหาอัจฉริยะทั้งจากคำและความหมาย Free รองรับ **2,500 บุ๊กมาร์ก** และไม่มีจำกัดจำนวนอุปกรณ์ หากไม่ใช้การซิงค์ Pro แต่ละอุปกรณ์จะมีคลังของตัวเอง เมื่อถึง 2,500 จะไม่มีการลบข้อมูล: ยังอ่าน ค้นหา และส่งออกได้ เพียงหยุดการบันทึกใหม่เท่านั้น Pro จะยกเลิกขีดจำกัดและซิงค์ได้สูงสุดห้าอุปกรณ์ผ่าน P2P

## นำเข้าจาก Pocket

ไปที่ **การตั้งค่า → นำเข้า** แล้วเลือก `ril_export.html` หรือ CSV จาก Pocket ก่อนบันทึกจะแสดงตัวอย่างลิงก์ วันที่ และแท็ก สถานะอ่านแล้ว ยังไม่อ่าน และเก็บถาวรจะถูกเก็บไว้ หากถึงขีดจำกัด Free ผลลัพธ์จะแจ้งจำนวนที่นำเข้าและแจ้งว่าถึงขีดจำกัดแล้ว โดยไม่เรียกส่วนที่เหลือว่าเป็นรายการที่ข้าม

## โน้ต AI และการซิงค์

เครื่องมือแก้ไขรองรับโน้ตแบบมีโครงสร้าง ตาราง และลิงก์ระหว่างเอกสาร AI ในเครื่องด้วย WebLLM/Ollama แชต RAG แฟลชการ์ด และการซิงค์ P2P เป็นฟีเจอร์ Pro หากใช้ API key ของตนเอง ให้ปฏิบัติตามเงื่อนไขของผู้ให้บริการนั้น

## สำรองข้อมูลและขอความช่วยเหลือ

เก็บสำเนา `.bmf` หลายชุดไว้ต่างสถานที่ การกู้คืนต้องใช้รหัสผ่านหลัก หากบันทึกไม่ได้ให้ตรวจตัวนับ Free หากซิงค์ไม่ได้ให้ตรวจเครือข่าย ไฟร์วอลล์ และ ID อุปกรณ์ อย่าส่งรหัสผ่านหรือคำกู้คืนให้ฝ่ายสนับสนุน
