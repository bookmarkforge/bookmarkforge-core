**版本：** 1.0.0 · **最后更新：** 2026年9月 · **许可证：** MIT

## 1. 简介

BookmarkForge是一个**本地优先**的个人知识应用，让您可以保存书签、做笔记、通过交互式图表组织知识、直接在浏览器中使用AI，并在设备之间同步而无需依赖中央服务器。

**使BookmarkForge独特的特点：**

- **您的书签、笔记和文档位于您的浏览器中**（IndexedDB/RxDB）。保险库内容不会发送给BookmarkForge；如果您使用外部AI提供商，它只接收您通过该功能明确发送的内容。
- **端到端加密**，使用AES-GCM和Argon2id。甚至开发人员也无法读取您的保险库。
- **本地AI**，可离线工作且不将您的数据发送给第三方。
- **P2P同步**，在您的设备之间进行，无需中央服务器。
- **无订阅。** 一次性付款，永久属于您。

## 2. 入门指南

### 2.1 系统要求

- 现代浏览器：Chrome、Edge、Firefox、Safari（16+）
- 推荐使用8 GB RAM
- 本地AI需要基本GPU（WebGPU）
- 互联网连接（用于初始设置和同步；离线使用可选）

### 2.2 安装

1. 打开 [bookmarkforgeapp.com](https://bookmarkforgeapp.com)
2. 点击**"Install App"**或**"Add to Home Screen"**
3. 应用程序将作为PWA（渐进式Web应用）安装
4. 您也可以将其用作浏览器扩展

### 2.3 初始设置

1. **主密码：** 最少12个字符。建议使用密码短语。
   - 使用Argon2id派生您的AES-GCM密钥（自ADR-019起为强制性）
   - **您的密码是唯一的密钥。** 如果丢失，无法恢复。
2. **恢复短语：** 将24个词保存在安全位置。
3. **设备ID：** 自动生成。用于激活Pro许可证。

### 2.4 书签工具

将**"Save to Forge"**按钮拖到浏览器的书签栏。每当您在网页上时，点击它即可将其保存为书签。

## 3. 主要功能

### 3.1 书签

- **虚拟化列表**，可处理100,000+项目而不会延迟
- **深度搜索：** 搜索已保存页面的全文
- **智能收藏：** 按标签自动组织
- **导入/导出：** 从Notion、Evernote、Chrome导入，或导出为.bmf、Markdown、PDF
- **Free：** 2,500个书签，包含智能搜索，无设备限制。达到2,500个时，您的数据仍可用于阅读、搜索和导出；只有新保存会暂停。**Pro：** 无限书签。

### 3.2 笔记编辑器

基于块的编辑器，具有：
- `/`命令用于快速插入块
- 拖放
- LaTeX用于数学
- Mermaid图表用于图表
- 50+语言的语法高亮
- **AI Copilot**用于实时帮助

### 3.3 知识图谱

您的笔记的交互式3D/2D可视化：
- 按标签、日期或"连接强度"过滤
- 可视化不相关笔记之间的语义相似性
- 探索您的想法如何随时间连接

### 3.4 闪卡

- 修改的Anki式**间隔重复（SRK）**算法
- 跟踪您的"遗忘曲线"以在完美时刻显示卡片
- 支持图像遮挡和文本删除
- **仅Pro可用**

### 3.5 语音命令

语音转动作引擎：
- 说"Hey BMF，找到我的生物笔记"
- 说"保存此页面"
- 通过Web Speech API 100%离线工作

### 3.6 Omnibar（Ctrl+K）

应用程序的大脑：
- 数学、单位转换
- 同时搜索书签和笔记
- 输入`>`以获取系统命令

## 4. BookmarkForge中的AI

### 4.1 使用您自己的API密钥的AI（Free）

- 使用Gemini、OpenAI、Anthropic或任何兼容的提供商
- 您直接向提供商支付令牌费用
- 应用程序动态地将请求路由到最佳模型
- **本地语义缓存：** 如果您提出类似问题，使用0个API令牌

### 4.2 本地AI — WebLLM/Ollama（Pro）

- 直接在您的浏览器中运行完整的AI模型（如Llama 3.2、Qwen 2.5）
- 使用您的GPU（WebGPU）
- **无需互联网连接**即可运行
- 4位量化（q4f16）可在硬件上运行
- **无令牌成本**且不向第三方发送数据

### 4.3 针对您数据的RAG聊天（Pro）

- AI在响应之前"读取"您的本地笔记
- 基于您的特定知识回答
- 具有本地语义缓存的混合架构
- 如果您提出类似问题，应用程序使用0个令牌和0个API调用

### 4.4 专家代理（Pro）

- 不同领域的专门代理
- 自动化复杂的分析任务

## 5. P2P同步

### 5.1 要求

- 两台设备在同一Wi-Fi网络上
- 防火墙必须允许WebRTC
- 同步ID匹配

### 5.2 设置

1. 转到**设置 > 同步**
2. 启用"启用P2P同步"
3. 确保两台设备在同一网络上
4. 确认同步ID匹配

### 5.3 故障排除

| 问题 | 解决方案 |
|---|---|
| 同步失败 | 验证两台设备在同一Wi-Fi上 |
| 防火墙阻止WebRTC | 配置防火墙以允许WebRTC |
| 同步ID不匹配 | 重新启动同步室 |
| 连接缓慢 | 检查网络延迟 |

## 6. 安全和隐私

### 6.1 加密

- **AES-GCM**，密钥由**Argon2id**派生（版本4）
- 密钥从不以明文存储
- 动态派生，仅存在于内存（RAM）中
- 使用浏览器的原生SubtleCrypto API

### 6.2 主密码

- 最少12个字符
- 不存在"忘记密码"功能
- 您的密码是唯一的密钥
- 如果丢失，**我们无法帮助您**
- 始终在安全位置保存.bmf备份

### 6.3 恢复

- 随时将您的保险库导出为`.bmf`文件
- 格式：使用您的主密钥加密的JSON
- 将其安全存储（USB、外部驱动器、加密云）
- 要恢复：转到**设置 > 恢复**并选择您的.bmf文件
- 恢复需要您的主密码

### 6.4 隐私政策

- **零知识：** 开发人员对您的密钥或数据零了解
- 无Google Analytics，无遥测，无跟踪像素
- 无中央服务器存储您的数据
- 按设计符合GDPR
- 许可证服务器在不访问您的保险库的情况下验证您的许可证

### 6.5 许可证验证

- Pro许可证在初始握手后在本地验证
- 无持续跟踪
- 使用RSA-PSS（SHA-256，salt 32）签名的许可证证明
- 连接时每48小时重新验证
- 超过30天的证明被entitlement服务器拒绝

## 8. 导入和导出

### 关于Pocket的说明

导入可识别Pocket的HTML导出（`ril_export.html`）和CSV文件。在保存任何内容之前，应用程序显示包含链接、日期和标签的预览。读取/存档状态被保留；如果在导入时达到Free限制，结果会诚实地报告导入了多少项目以及达到了限制，而不是将其余的算作被忽略。

### 8.1 导入

转到**设置 > 导入**：
- **来自Notion或Evernote的HTML/JSON**
- **Chrome书签导出**
- **.bmf备份**

### 8.2 导出

- **.bmf：** 完整加密备份
- **Markdown：** 可读格式的笔记
- **PDF：** 将笔记导出为PDF文档
- **JSON：** 结构化数据

### 8.3 备份和恢复

- 定期将您的保险库导出为.bmf
- 将其存储在安全位置
- 要恢复：转到**设置 > 恢复**并选择您的.bmf文件
- 恢复需要您的主密码

## 9. 故障排除

### 9.1 应用程序无法加载

1. 清除浏览器缓存
2. 将Chrome/Edge更新到最新版本
3. 检查您的磁盘是否已满
4. 禁用冲突的扩展（广告拦截器有时会阻止IndexedDB）

### 9.2 同步失败

1. 确保两台设备在同一Wi-Fi上
2. 检查防火墙是否允许WebRTC
3. 确认同步ID匹配
4. 如有必要，重新启动同步室

### 9.3 AI产生幻觉或回答不正确

1. AI可能会犯错 — 使用聊天中的"来源"链接进行验证
2. 在AI设置中调整"温度"
3. 如果使用本地AI，验证模型是否正确加载

### 9.4 扩展程序无法保存

1. 更新您尝试保存的页面
2. 确保您在另一个选项卡中登录了BookmarkForge
3. 重新安装书签工具

### 9.5 性能缓慢

1. 转到设置 > 高级并运行"数据库优化"
2. 检查系统诊断以了解CPU使用情况
3. 虚拟化处理大型列表，但繁重的笔记可能会影响RAM

### 9.6 数据库损坏

1. 使用"系统诊断"检查完整性
2. 如果损坏，从您的最后一个.bmf备份恢复

### 9.7 Pro许可证不起作用

1. 验证您的互联网连接是否工作（需要定期验证）
2. 尝试在**设置 > 许可证 > 重新验证**中重新验证
3. 如果问题持续存在，联系**bookmarkforge@proton.me**
4. 通过Whop在30天内可退款

### 9.8 许可证错误：SIGNING_KEY_INVALID

此错误表示服务器未正确配置。这不是用户问题。联系支持。

## 11. 常见问题

**是免费的吗？**
主应用程序是本地优先且免费的。高级AI功能和P2P同步需要Pro许可证。

**我可以在移动设备上使用吗？**
可以。通过Chrome（Android）或Safari（iOS）将其安装为PWA。支持离线访问和推送通知。

**我的文件在哪里？**
在浏览器的内部存储（IndexedDB）中。您可以随时将其导出为.bmf、Markdown或PDF。

**可以在没有互联网的情况下工作吗？**
100%。所有功能（编辑器、书签、图谱、本地AI、搜索）都可以在没有互联网连接的情况下工作。

**会消耗很多API令牌吗？**
不会。应用程序使用本地语义缓存算法。如果您提出相同问题的变体，它使用0个API令牌。

**电池消耗？**
本地AI使用WebGPU。在笔记本电脑上，它可能会更快消耗电池。在设置中禁用本地AI以节省电池。
