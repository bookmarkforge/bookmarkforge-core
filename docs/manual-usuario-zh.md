# 用户手册 — BookmarkForge v1

**版本：** 1.0.0 · **最后更新：** 2026年9月 · **许可证：** MIT

## 1. 概览

BookmarkForge用于保存书签、笔记和文档，帮助你整理个人知识。保险库内容保存在浏览器的本地存储中，不会发送给BookmarkForge。如果使用外部AI服务，只有你明确发送给该功能的数据才会传给对应提供商。

保险库在设备本地使用AES-GCM加密，密钥由Argon2id根据主密码派生。主密码无法由支持人员重置，请妥善保管。

## 2. 开始使用

1. 打开 [bookmarkforge.com](https://bookmarkforge.com)。
2. 浏览器支持时，可以安装为PWA，也可以直接使用网页应用。
3. 创建至少12个字符的主密码。
4. 将24个恢复词保存在安全位置。
5. 定期导出加密的`.bmf`备份。

首次加载后可以离线使用。通过书签工具或浏览器扩展，可以快速保存当前页面。

## 3. 书签与搜索

- 保存网页的URL、标题、日期和标签。
- Free包含智能搜索，可以按关键词或含义查找内容。
- Free支持**1,000个书签**，没有设备数量上限。但在没有Pro同步时，每台设备拥有独立的保险库。
- 达到1,000个后不会删除任何内容：阅读、搜索和导出仍然可用，只有新保存会暂停。
- Pro取消数量上限，并支持最多三台设备进行P2P同步。

## 4. 从Pocket导入

打开**设置 → 导入**，选择`ril_export.html`或从Pocket导出的CSV。应用会自动识别格式，并在写入前显示链接数量、日期和标签的预览。

已读、未读和归档状态都会保留。如果导入达到Free上限，结果会明确显示已导入的数量以及已达到上限，不会把剩余内容错误地统计为跳过。

## 5. 笔记、AI和同步

编辑器支持结构化笔记、表格和文档之间的链接。使用自己的API密钥调用AI时，适用对应服务商的条款和隐私政策，费用也直接支付给服务商。

WebLLM/Ollama本地AI、基于个人数据的RAG聊天、抽认卡和P2P同步属于Pro功能。P2P同步可能需要连接同一个Wi-Fi网络，或配置可用的信令服务。

## 6. 备份与恢复

- 在迁移或重要操作前创建`.bmf`备份。
- 将多份备份保存到不同位置。
- 恢复需要主密码。
- 如果同时丢失主密码、恢复词和可用备份，支持人员也无法恢复保险库。

## 7. Free与Pro

| 功能 | Free | Pro |
|---|---|---|
| 书签 | 1,000个 | 无限 |
| 设备 | 无数量上限，保险库分开 | 最多3台，支持P2P |
| 智能搜索 | 包含 | 包含 |
| 使用自己的密钥调用AI | 支持 | 支持 |
| 本地AI和RAG聊天 | 不支持 | 支持 |
| JSON/HTML和`.bmf`导出 | 支持 | 支持 |
| 费用 | 免费 | v1买断式许可证 |

前往**设置 → Pro**，通过Whop结账并激活。激活会联系许可证服务，但不会上传你的保险库。

## 8. 故障排查

- **应用无法打开：** 更新浏览器，检查磁盘空间，并暂时停用可能冲突的扩展。
- **无法保存：** 查看Free计数器；达到1,000后先导出、删除项目或激活Pro。
- **同步失败：** 检查网络、防火墙和两台设备的同步ID。
- **许可证无法激活：** 检查网络，并只向支持人员提供错误代码，不要提供密码或恢复词。

## 9. 隐私与支持

默认情况下，保险库内容保留在设备本地。支付、许可证、远程AI、P2P信令以及经过同意的错误报告等可选服务，只会处理各自所需的技术数据。

支持邮箱：`bookmarkforge@proton.me`。支持人员不会索要你的密码或恢复词。
