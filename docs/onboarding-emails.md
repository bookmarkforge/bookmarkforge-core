# Onboarding emails

## Welcome

Smart search is included free, so you can explore your vault without activating a paid plan. BookmarkForge works on any device and has no device cap for the vaults you create on each device.

## Privacy and pricing

Raindrop charges yearly for smart search and similar features; BookmarkForge keeps smart search included free and makes the local-first limits clear before checkout.

## Getting started

Save your recovery kit, create a backup, and try capture, folders, and smart search on any device. There is no device cap in the application experience; each device keeps its own local vault unless you explicitly synchronize it.
