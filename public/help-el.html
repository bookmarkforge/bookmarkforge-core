SLA υποστήριξης — πόσο γρήγορα απαντάμε

Ένας μόνο συντηρητής. Το χρηματοκιβώτιο είναι κρυπτογραφημένο — δεν ζητάμε ποτέ τον κωδικό του χρηματοκιβωτίου σου ή τη φράση ανάκτησης 24 λέξεων. Η υποστήριξη είναι best-effort για το Free, δεσμευμένη για τους επί πληρωμή βαθμούς.

ProEmail bookmarkforge@proton.me (θέμα: Pro)48hΣυμπεριέλαβε το κείμενο διάγνωσης από Ρυθμίσεις → Βοήθεια → Αντιγραφή διάγνωσης

Δεν μπορούμε να δούμε τους σελιδοδείκτες, τις σημειώσεις, τα URL ή τις εντολές σου. Συμπεριέλαβε μόνο τη διάγνωση παρακάτω — περιέχει μετρήσεις και εκδόσεις, ποτέ περιεχόμενο χρηματοκιβωτίου.

Αντιμετώπιση προβλημάτων — τα περισσότερα θέματα σε 30 δευτερόλεπτα

Χρηματοκιβώτιο κλειδωμένο / λάθος κωδικός

Οι κωδικοί είναι ευαίσθητοι σε πεζά/κεφαλαία και σε κενά. Αν άλλαξες διάταξη (π.χ. AZERTY→QWERTY) ξαναπληκτρολόγησε αργά. Μετά από 5 αποτυχημένα ξεκλειδώματα, περίμενε 1 λεπτό. Αν έχασες τον κωδικό, χρησιμοποίησε τη φράση ανάκτησης 24 λέξεων που εμφανίστηκε μία φορά κατά τη δημιουργία χρηματοκιβωτίου (BF-E101). Χωρίς αυτή η ανάκτηση είναι αδύνατη από σχεδιασμό — δεν έχουμε backdoor.

Αποθηκευτικός χώρος προγράμματος περιήγησης πλήρης

Το IndexedDB quota είναι ανά πρόγραμμα περιήγησης (συνήθως 60–80% του δίσκου). Όταν γεμίσει, οι αποθηκεύσεις αποτυγχάνουν με BF-E103. Διόρθωση: Ρυθμίσεις → Αποθήκευση → Συμπύκνωση βάσης δεδομένων μετά Εκκαθάριση cache AI. Ή Εξαγωγή αντιγράφου ασφαλείας (.bmf) → Διαγραφή παλιών διανυσμάτων. Έλεγξε το % αποθήκευσης στη διάγνωση — πάνω από 80% εμφανίζουμε banner.

Ο P2P συγχρονισμός δεν συνδέεται

Και οι δύο συσκευές πρέπει να είναι online και ξεκλειδωμένες ταυτόχρονα (WebRTC). Δεν υπάρχει TURN relay εξ ορισμού — ορισμένα εταιρικά δίκτυα μπλοκάρουν το P2P. Δοκίμασε: και οι δύο στο ίδιο Wi-Fi → σύζευξη QR → κράτα την εφαρμογή ανοιχτή. Αν BF-E105, δοκίμασε Βοήθεια → Διάγνωση → P2P (WebRTC) — αν λέει μη διαθέσιμο, το πρόγραμμα περιήγησης/δίκτυό σου μπλοκάρει το WebRTC.

Τοπικό AI (WebLLM) δεν τρέχει

Απαιτεί WebGPU + ~4 GB ελεύθερη RAM + άδεια Pro. Έλεγξε Βοήθεια → Διάγνωση → WebGPU/WebLLM. Αν BF-E106: ενημέρωσε Chrome/Edge στην τελευταία έκδοση, ενεργοποίησε chrome://flags/#enable-unsafe-webgpu, ή μετάβα σε Ollama (οποιοδήποτε μοντέλο τρέχεις τοπικά — δεν χρειάζεται API key επίσης).

Αργή αναζήτηση ή εισαγωγή

Η πρώτη εισαγωγή χτίζει HNSW διανύσματα — βαριά για CPU. Κράτα την καρτέλα ανοιχτή. Για 10k+ σελιδοδείκτες χρησιμοποίησε Ρυθμίσεις → Για προχωρημένους → Εξαναγκασμένη επανεπεξεργασία. Αν παραμένει, το Αντιγραφή διάγνωσης δείχνει vectorIndexLoad και καθυστέρηση ερωτήματος.

Κωδικοί σφαλμάτων BF-E* — αντίγραψε τον κωδικό, μετάβα στη διόρθωση

Κάθε κρίσιμο σφάλμα εμφανίζει έναν κωδικό όπως BF-E101. Κλικ στον κωδικό στην εφαρμογή ή αναζήτησέ τον εδώ.

ΚωδικόςΣημασίαΔιόρθωση
BF-E101Κωδικός χρηματοκιβωτίου ξεχασμένος / απαιτείται φράση seedΔεν μπορούμε να ανακτήσουμε κωδικούς. Κατά τη δημιουργία χρηματοκιβωτίου δείχνουμε φράση 24 λέξεων μία φορά — γράψε την στο χαρτί. Χρησιμοποίησέ την για επαναφορά. Χωρίς φράση = χρηματοκιβώτιο μη ανακτήσιμο. Κανένα ticket δεν θα το ανακτήσει.
BF-E102Χρηματοκιβώτιο κλειδωμένο / λάθος κωδικόςΞαναπληκτρολόγησε τον κωδικό ακριβώς. Μετά από 5 αποτυχίες περίμενε 60s. Αν άλλαξες κωδικό πρόσφατα, δοκίμασε τον προηγούμενο — η εναλλαγή κρατά το τελευταίο salt για rollback.
BF-E103Το quota αποθήκευσης ξεπεράστηκεΠήγαινε στο Ρυθμίσεις → Αποθήκευση: Συμπύκνωση DB + Εκκαθάριση cache AI. Εξαγωγή αντιγράφου .bmf αν χρειάζεται. Δες Αντιμετώπιση προβλημάτων §Αποθήκευση.
BF-E104IndexedDB μπλοκαρισμένο / ιδιωτική περιήγησηΤο IndexedDB μπλοκάρεται σε ιδιωτικό/incognito ή από πολιτική αποθήκευσης. Χρησιμοποίησε κανονικό παράθυρο. Έλεγξε Βοήθεια → Διάγνωση → Αποθήκευση.
BF-E105P2P / WebRTC μη διαθέσιμοΤο πρόγραμμα περιήγησης ή το δίκτυο μπλοκάρει το WebRTC. Δοκίμασε άλλο πρόγραμμα/δίκτυο, απενεργοποίησε αυστηρό firewall, ή χρησιμοποίησε Εξαγωγή/Εισαγωγή αντί για live συγχρονισμό.
BF-E106Το τοπικό AI (WebLLM) δεν μπορεί να τρέξει σε αυτή τη συσκευήΧρειάζεται WebGPU + shader-f16 + 4 GB RAM + Pro. Ενημέρωσε το πρόγραμμα περιήγησης, ή χρησιμοποίησε Ollama / cloud πάροχο με το δικό σου key.
BF-E107Αποτυχία εισαγωγής αντιγράφου ασφαλείας (λάθος κωδικός / κατεστραμμένο αρχείο)Για .bmf (κρυπτογραφημένο) χρειάζεσαι τον κωδικό εξαγωγής, όχι τον κωδικό χρηματοκιβωτίου. Για JSON, βεβαιώσου ότι το αρχείο δεν περικόπηκε.
BF-E201Άδεια Pro μη έγκυρη / απέτυχε ο έλεγχοςΈλεγξε Ρυθμίσεις → Pro: ξαναβάλε το κλειδί. Οι offline έλεγχοι κάνουν cache· συνδέσου μία φορά για επανεπικύρωση μέσω Whop.
BF-E202Φτάστηκε το δωρεάν όριο (2.500 σελιδοδείκτες)Το δωρεάν είναι 2.500. Διέγραψε ή αναβάθμισε σε Pro Lifetime v1 για απεριόριστο. Η εξαγωγή είναι πάντα διαθέσιμη.

Συμβουλή υποστήριξης: κλικ στο Αντιγραφή διάγνωσης του σφάλματος αντιγράφει κωδικό + πλαίσιο με ένα κλικ — επικόλλησέ το στη συζήτησή σου στο GitHub ή στο email.

Αντιγραφή διάγνωσης με απόκρυψη — τι επικολλάς στην υποστήριξη

Στην εφαρμογή: Ρυθμίσεις → Για προχωρημένους (ή Βοήθεια → Διάγνωση) → Αντιγραφή διάγνωσης. Μοιάζει με αυτό — χωρίς περιεχόμενο χρηματοκιβωτίου, χωρίς URL, χωρίς εντολές:

BookmarkForge v1.0.0 | Chrome 126 | Χρηματοκιβώτιο: 847 σελιδοδείκτες, 12 έγγραφα Αποθήκευση: 42% (IndexedDB OK) | Τελευταίο αντίγραφο ασφαλείας: πριν 2 ημέρες (.bmf κρυπτογραφημένο) P2P: μη συνδεδεμένο | Συγχρονισμός: ποτέ | Τοπικό AI: WebLLM δεν φορτώθηκε Σφάλματα: 0 τις τελευταίες 7η | BF-E: κανένα | Build: a1b2c3d

Τι περιέχει: έκδοση εφαρμογής, πρόγραμμα περιήγησης, μετρήσεις (σελιδοδείκτες/έγγραφα/διανύσματα), % αποθήκευσης + quota, κατάσταση P2P, κατάσταση AI, μετρήσεις σφαλμάτων & τελευταίος κωδικός BF-E, build hash. Χρησιμοποιεί salted hash της IP — δεν αποθηκεύουμε ποτέ IP. Δες Απόρρητο §3/§6.

Αν δεν μπορείς να ανοίξεις την εφαρμογή: συμπεριέλαβε πρόγραμμα περιήγησης + OS + βήματα αναπαραγωγής + τον κωδικό BF-E* στην οθόνη. Αυτό αρκεί για το 90% των tickets.
