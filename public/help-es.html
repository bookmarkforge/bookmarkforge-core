Solución de Problemas — la mayoría de problemas en 30 segundos

Bóveda bloqueada / contraseña incorrecta

Las contraseñas distinguen mayúsculas/minúsculas y espacios en blanco. Si cambiaste el diseño (ej. AZERTY→QWERTY) escribe lentamente. Después de 5 desbloqueos fallidos, espera 1 minuto. Si perdiste la contraseña, usa la frase de recuperación de 24 palabras mostrada una vez al crear la bóveda (BF-E101). Sin ella la recuperación es imposible por diseño — no tenemos puerta trasera.

Almacenamiento del navegador lleno

La cuota de IndexedDB es por navegador (típicamente 60–80% del disco). Cuando está lleno, las guardas fallan con BF-E103. Solución: Configuración → Almacenamiento → Compactar base de datos luego Limpiar caché de IA. O Exportar respaldo (.bmf) → Eliminar vectores antiguos. Ver % de almacenamiento en diagnóstico — arriba de 80% mostramos un banner.

Sincronización P2P no conecta

Ambos dispositivos deben estar en línea y desbloqueados al mismo tiempo (WebRTC). Sin relay TURN por defecto — algunas redes corporativas bloquean P2P. Prueba: ambos en el mismo Wi-Fi → emparejar QR → mantener la app abierta. Si BF-E105, prueba Ayuda → Diagnósticos → P2P (WebRTC) — si dice no disponible, tu navegador/red bloquea WebRTC.

IA Local (WebLLM) no ejecuta

Requiere WebGPU + ~4 GB de RAM libre + licencia Pro. Verifica Ayuda → Diagnósticos → WebGPU/WebLLM. Si BF-E106: actualiza Chrome/Edge a lo último, habilita chrome://flags/#enable-unsafe-webgpu, o cambia a Ollama (cualquier modelo que ejecutes localmente — tampoco se necesita API key).

Búsqueda o importación lenta

La primera importación construye vectores HNSW — pesado en CPU. Mantén la pestaña abierta. Para 10k+ marcadores usa Configuración → Avanzado → Forzar reprocesar. Si persiste, Copiar diagnóstico muestra vectorIndexLoad y latencia de consulta.

Códigos de error BF-E* — copia el código, salta a la solución

Cada error crítico muestra un código como BF-E101. Haz clic en el código en la app o búscalo aquí.

CódigoSignificadoSolución
BF-E101Contraseña de bóveda olvidada / frase semilla requeridaNo podemos recuperar contraseñas. Al crear la bóveda mostramos una frase de 24 palabras una vez — escríbela en papel. Úsala para restablecer. Sin frase = bóveda irrecuperable. Ningún ticket la recuperará.
BF-E102Bóveda bloqueada / contraseña incorrectaEscribe la contraseña exactamente. Después de 5 fallos espera 60s. Si rotaste la contraseña recientemente, prueba la anterior — la rotación mantiene la última sal para reversión.

Tip de soporte: hacer clic en Copiar diagnóstico del error copia código + contexto en un clic — pégalo en tu Discusión de GitHub o email.

Copiar un diagnóstico redactado — qué pegas al soporte

En la app: Configuración → Avanzado (o Ayuda → Diagnósticos) → Copiar diagnóstico. Se ve así — sin contenido de bóveda, sin URLs, sin prompts:

BookmarkForge v1.0.0 | Chrome 126 | Bóveda: 847 marcadores, 12 docs Almacenamiento: 42% (IndexedDB OK) | Último respaldo: hace 2 días (.bmf cifrado) P2P: no conectado | Sync: nunca | IA Local: WebLLM no cargado Errores: 0 últimos 7d | BF-E: ninguno | Build: a1b2c3d

Qué contiene: versión de app, navegador, conteos (marcadores/docs/vectores), % de almacenamiento + cuota, estado P2P, estado IA, conteos de errores & último código BF-E, hash de build. Usa un hash con sal de IP — nunca almacenamos IP. Ver Privacidad §3/§6.

Si no puedes abrir la app: incluye navegador + SO + pasos para reproducir + el código BF-E* en pantalla. Eso es suficiente para 90% de los tickets.
