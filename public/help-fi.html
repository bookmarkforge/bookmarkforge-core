Tuen SLA — kuinka nopeasti vastaamme

Yksi ylläpitäjä. Holvi on salattu — emme koskaan kysy holvisalasanaasi tai 24-sanaisen palautuslauseesi. Tuki on parhaan mukaan Ilmaiselle, sitoutunut maksullisille tasoille.

Vianetsintä — useimmat ongelmat 30 sekunnissa

Holvi lukittu / väärä salasana

Salasanat ovat kirjain- ja välilyöntiherkkiä. Jos vaihdoit asettelua (esim. AZERTY→QWERTY), kirjoita hitaasti. 5 epäonnistuneen avauksen jälkeen odota 1 minuutti. Jos kadotit salasanan, käytä 24-sanaisen palautuslauseen, joka näytetään kerran holvia luotaessa (BF-E101). Ilman sitä palautus on mahdotonta suunnittelun mukaan — meillä ei ole takaporttia.

Selaimen tallennustila täynnä

IndexedDB-kiintiö on selainkohtainen (tyypillisesti 60–80 % levystä). Täyttyessään tallennukset epäonnistuvat koodilla BF-E103. Korjaus: Settings → Storage → Compact database, sitten Clear AI cache. Tai Export backup (.bmf) → Delete old vectors. Tarkista tallennus-% diagnostiikassa — yli 80 % näytämme bannerin.

P2P-synkronointi ei yhdistä

Molempien laitteiden on oltava verkossa ja avattuina samaan aikaan (WebRTC). TURN-rele ei oletuksena — jotkin yritysverkot estävät P2P:n. Kokeile: molemmat samassa Wi-Fi:ssä → QR-paritus → pidä sovellus auki. Jos BF-E105, testaa Help → Diagnostics → P2P (WebRTC) — jos se kertoo ei saatavilla, selaimesi/verkkosi estää WebRTC:n.

Paikallinen tekoäly (WebLLM) ei toimi

Vaatii WebGPU:n + ~4 Gt vapaata RAM-muistia + Pro-lisenssin. Tarkista Help → Diagnostics → WebGPU/WebLLM. Jos BF-E106: päivitä Chrome/Edge uusimpaan, ota käyttöön chrome://flags/#enable-unsafe-webgpu, tai siirry Ollamaan (mikä tahansa paikallisesti ajamasi malli — ei API-avainta tarvita).

Hidas haku tai tuonti

Ensimmäinen tuonti rakentaa HNSW-vektorit — CPU-raskasta. Pidä välilehti auki. 10 000+ kirjanmerkille käytä Settings → Advanced → Force reprocess. Jos jatkuu, Copy diagnostic näyttää vectorIndexLoad:n ja kyselyn viiveen.

Virhekoodit BF-E* — kopioi koodi, hyppää korjaukseen

Jokainen kriittinen virhe näyttää koodin kuten BF-E101. Napsauta koodia sovelluksessa tai etsi se täältä.

KoodiMerkitysKorjaus

BF-E102Holvi lukittu / väärä salasanaKirjoita salasana uudelleen tarkasti. 5 epäonnistumisen jälkeen odota 60 s. Jos vaihdoit salasanan äskettäin, kokeile edellistä — kierrätys säilyttää viimeisen suolan palautusta varten.

Kopioi salattu diagnostiikka — mitä liität tukeen

Sovelluksessa: Settings → Advanced (tai Help → Diagnostics) → Copy diagnostic. Se näyttää tältä — ei holvisisältöä, ei URL-osoitteita, ei kehotteita:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Mitä se sisältää: sovellusversio, selain, määrät (kirjanmerkit/asiakirjat/vektorit), tallennus-% + kiintiö, P2P-tila, tekoälytila, virhemäärät & viimeisin BF-E-koodi, build-hash. Käyttää suolattua IP-hashia — emme koskaan tallenna IP:tä. Katso Tietosuoja §3/§6.

Jos et voi avata sovellusta: sisällytä selain + käyttöjärjestelmä + toistovaiheet + ruudulla oleva BF-E*-koodi. Se riittää 90 % tiketeistä.
