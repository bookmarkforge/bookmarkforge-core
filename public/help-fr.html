Dépannage — la plupart des problèmes en 30 secondes

Coffre-fort verrouillé / mot de passe incorrect

Les mots de passe sont sensibles à la casse et aux espaces. Si vous avez changé de disposition clavier (ex. AZERTY→QWERTY), retapez-le lentement. Après 5 tentatives échouées, attendez 1 minute. Si vous avez perdu votre mot de passe, utilisez la phrase de récupération de 24 mots affichée une seule fois à la création du coffre-fort (BF-E101). Sans cette phrase, la récupération est impossible par conception — aucun moyen de contournement n'existe.

Espace de stockage du navigateur saturé

Le quota IndexedDB dépend du navigateur (généralement 60 à 80 % de l'espace disque). S'il est saturé, les enregistrements échouent avec BF-E103. Solution : Paramètres → Stockage → Compacter la base de données puis Vider le cache IA. Ou Exporter une sauvegarde (.bmf) → Supprimer d'anciens vecteurs. Vérifiez le pourcentage de stockage dans le diagnostic — au-delà de 80 %, une bannière s'affiche.

La synchronisation P2P ne se connecte pas

Les deux appareils doivent être connectés et déverrouillés en même temps (WebRTC). Par défaut, aucun relais TURN n'est utilisé — certains réseaux d'entreprise bloquent le P2P. Essayez : les deux appareils sur le même Wi-Fi → appairage par QR → laissez l'application ouverte. Si vous obtenez BF-E105, testez via Aide → Diagnostics → P2P (WebRTC) — s'il indique « indisponible », votre navigateur ou votre réseau bloque WebRTC.

L'AI local (WebLLM) ne fonctionne pas

Nécessite WebGPU + ~4 Go de RAM libre + une licence Pro. Vérifiez Aide → Diagnostics → WebGPU/WebLLM. Si vous obtenez BF-E106 : mettez à jour Chrome/Edge vers la dernière version, activez chrome://flags/#enable-unsafe-webgpu, ou passez à Ollama (n'importe quel modèle exécuté localement — aucune clé API n'est nécessaire).

Recherche ou import lent

Le premier import construit les vecteurs HNSW — cela sollicite fortement le CPU. Laissez l'onglet ouvert. Pour plus de 10 000 favoris, utilisez Paramètres → Avancé → Forcer le retraitement. Si le problème persiste, Copier le diagnostic affiche vectorIndexLoad et la latence des requêtes.

Codes d'erreur BF-E* — copiez le code pour accéder au correctif

Chaque erreur critique affiche un code tel que BF-E101. Cliquez sur le code dans l'application ou recherchez-le ici.

CodeSignificationCorrectif
BF-E101Mot de passe du coffre-fort oublié / phrase de récupération requiseNous ne pouvons pas récupérer les mots de passe. À la création du coffre-fort, une phrase de récupération de 24 mots est affichée une seule fois — notez-la sur papier. Utilisez-la pour réinitialiser. Sans cette phrase, le coffre-fort est irrécupérable. Aucun ticket ne pourra le récupérer.
BF-E102Coffre-fort verrouillé / mot de passe incorrectRetapez le mot de passe exactement. Après 5 échecs, attendez 60 secondes. Si vous avez récemment modifié votre mot de passe, essayez l'ancien — la rotation conserve le dernier sel pour permettre une restauration.
BF-E103Quota de stockage dépasséAllez dans Paramètres → Stockage : Compacter la base de données + Vider le cache IA. Exportez une sauvegarde .bmf si nécessaire. Voir Dépannage §Stockage.
BF-E104IndexedDB bloqué / navigation privéeIndexedDB est bloqué en navigation privée/incognito ou par une politique de stockage. Utilisez une fenêtre normale. Vérifiez Aide → Diagnostics → Stockage.
BF-E105P2P / WebRTC indisponibleVotre navigateur ou votre réseau bloque WebRTC. Essayez un autre navigateur/réseau, désactivez un pare-feu trop restrictif, ou utilisez Exporter/Importer plutôt que la synchronisation en direct.
BF-E106L'AI local (WebLLM) ne peut pas s'exécuter sur cet appareilNécessite WebGPU + shader-f16 + 4 Go de RAM + Pro. Mettez à jour votre navigateur, ou utilisez Ollama / un fournisseur cloud avec votre propre clé.
BF-E107Échec de l'import de sauvegarde (mauvais mot de passe / fichier corrompu)Pour un fichier .bmf (chiffré), vous avez besoin du mot de passe d'exportation, et non du mot de passe du coffre-fort. Pour un fichier JSON, assurez-vous qu'il n'a pas été tronqué.
BF-E201Licence Pro invalide / vérification expiréeVérifiez Paramètres → Pro : saisissez à nouveau votre clé. Les vérifications hors ligne sont mises en cache ; reconnectez-vous une fois pour la revalider via Whop.
BF-E202Limite Free atteinte (2,500 favoris)L'offre Free est limitée à 2,500 favoris. Supprimez des éléments ou passez à Pro Lifetime v1 pour un usage illimité. L'export reste toujours disponible.

Copier un diagnostic anonymisé — ce que vous envoyez au support

Dans l'application : Paramètres → Avancé (ou Aide → Diagnostics) → Copier le diagnostic. Il ressemble à ceci — aucun contenu du coffre-fort, aucune URL, aucun prompt :

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Ce qu'il contient : version de l'application, navigateur, comptes (favoris/documents/vecteurs), pourcentage de stockage + quota, état P2P, état de l'AI, nombre d'erreurs et dernier code BF-E, hash de build. Utilise un hash salé de l'IP — nous ne stockons jamais l'IP. Voir Politique de confidentialité §3/§6.

Si vous ne pouvez pas ouvrir l'application : indiquez votre navigateur + système d'exploitation + les étapes pour reproduire le problème + le code BF-E* affiché à l'écran. Cela suffit pour 90 % des tickets.
