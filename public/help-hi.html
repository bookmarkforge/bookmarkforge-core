सपोर्ट SLA — कितनी जल्दी जवाब

सिंगल मेंटेनर। वॉल्ट एन्क्रिप्टेड है — हम आपका वॉल्ट पासवर्ड या 24-शब्द रिकवरी फ़्रेज़ कभी नहीं माँगते। फ्री के लिए सपोर्ट बेस्ट-एफ़र्ट, पेड टियर्स के लिए कमिटेड।

हम आपके बुकमार्क, नोट्स, URL या प्रॉम्प्ट्स नहीं देख सकते। सिर्फ नीचे वाला डायग्नॉस्टिक शामिल करें — उसमें काउंट्स और वर्ज़न होते हैं, वॉल्ट कंटेंट कभी नहीं।

ट्रबलशूटिंग — 30 सेकंड में ज़्यादातर मुद्दे

वॉल्ट लॉक / गलत पासवर्ड

पासवर्ड केस- और व्हाइटस्पेस-सेंसिटिव होते हैं। अगर लेआउट बदला (जैसे AZERTY→QWERTY) तो धीरे-धीरे टाइप करें। 5 फ़ेल्ड अनलॉक्स के बाद, 1 मिनट इंतज़ार करें। अगर पासवर्ड खो गया, तो वॉल्ट बनाते वक्त एक बार दिखाया गया 24-शब्द रिकवरी फ़्रेज़ इस्तेमाल करें (BF-E101)। बिना उसके रिकवरी बाय डिज़ाइन इम्पॉसिबल है — हमारा कोई बैकडोर नहीं।

ब्राउज़र स्टोरेज फुल

IndexedDB कोटा प्रति-ब्राउज़र होता है (आम तौर पर डिस्क का 60–80%)। फुल होने पर सेव्स BF-E103 के साथ फ़ेल होते हैं। फिक्स: Settings → Storage → Compact database फिर Clear AI cache। या Export backup (.bmf) → Delete old vectors। डायग्नॉस्टिक में स्टोरेज % चेक करें — 80% से ऊपर बैनर दिखता है।

P2P सिंक कनेक्ट नहीं हो रहा

दोनों डिवाइस एक साथ ऑनलाइन और अनलॉक होने चाहिए (WebRTC)। डिफ़ॉल्ट रूप से कोई TURN रिले नहीं — कुछ कॉर्पोरेट नेटवर्क P2P ब्लॉक करते हैं। ट्राय करें: दोनों एक ही Wi-Fi पर → QR पेयर → ऐप खुला रखें। अगर BF-E105, तो टेस्ट करें Help → Diagnostics → P2P (WebRTC) — अगर अनअवेलेबल बताए, तो आपका ब्राउज़र/नेटवर्क WebRTC ब्लॉक कर रहा है।

लोकल AI (WebLLM) नहीं चल रहा

WebGPU + ~4 GB फ्री RAM + Pro लाइसेंस चाहिए। चेक करें Help → Diagnostics → WebGPU/WebLLM। अगर BF-E106: Chrome/Edge लेटेस्ट में अपडेट करें, chrome://flags/#enable-unsafe-webgpu एनेबल करें, या Ollama पर स्विच करें (लोकली चलाया जा सकने वाला कोई भी मॉडल — बिना API की भी)।

स्लो सर्च या इम्पोर्ट

पहला इम्पोर्ट HNSW वेक्टर्स बिल्ड करता है — CPU हेवी। टैब खुला रखें। 10k+ बुकमार्क्स के लिए Settings → Advanced → Force reprocess इस्तेमाल करें। अगर बना रहे, तो Copy diagnostic में vectorIndexLoad और क्वेरी लैटेंसी दिखता है।

एरर कोड्स BF-E* — कोड कॉपी करें, फिक्स पर जाएं

हर क्रिटिकल एरर BF-E101 जैसा कोड दिखाता है। ऐप में कोड क्लिक करें या यहाँ सर्च करें।

कोडमतलबफिक्स
BF-E101वॉल्ट पासवर्ड भूल गया / सीड फ़्रेज़ ज़रूरीहम पासवर्ड रिकवर नहीं कर सकते। वॉल्ट बनाते वक्त हम 24-शब्द फ़्रेज़ एक बार दिखाते हैं — कागज़ पर लिख लें। रिसेट के लिए इस्तेमाल करें। फ़्रेज़ नहीं = वॉल्ट अनरिकवरेबल। कोई टिकट इसे रिकवर नहीं करेगा।
BF-E102वॉल्ट लॉक / गलत पासवर्डपासवर्ड बिल्कुल वैसे टाइप करें। 5 फ़ेल्योर्स के बाद 60s इंतज़ार करें। अगर हाल में पासवर्ड रोटेट किया, तो पिछला ट्राय करें — रोटेशन रोलबैक के लिए लास्ट सॉल्ट रखता है।
BF-E103स्टोरेज कोटा एक्सीडेडSettings → Storage पर जाएं: Compact DB + Clear AI cache। ज़रूरत हो तो .bmf बैकअप एक्सपोर्ट करें। Troubleshooting §Storage देखें।
BF-E104IndexedDB ब्लॉक्ड / प्राइवेट ब्राउज़िंगप्राइवेट/इनकॉग्निटो या स्टोरेज पॉलिसी में IndexedDB ब्लॉक्ड है। नॉर्मल विंडो इस्तेमाल करें। चेक करें Help → Diagnostics → Storage।
BF-E105P2P / WebRTC अनअवेलेबलब्राउज़र या नेटवर्क WebRTC ब्लॉक कर रहा है। दूसरा ब्राउज़र/नेटवर्क ट्राय करें, स्ट्रिक्ट फ़ायरवॉल डिसेबल करें, या लाइव सिंक के बजाय Export/Import इस्तेमाल करें।
BF-E106लोकल AI (WebLLM) इस डिवाइस पर नहीं चल सकताWebGPU + shader-f16 + 4 GB RAM + Pro चाहिए। ब्राउज़र अपडेट करें, या Ollama / अपनी खुद की चाबी वाला क्लाउड प्रोवाइडर इस्तेमाल करें।
BF-E107बैकअप इम्पोर्ट फ़ेल (गलत पासवर्ड / करप्ट फ़ाइल).bmf (एन्क्रिप्टेड) के लिए आपको एक्सपोर्ट पासवर्ड चाहिए, वॉल्ट पासवर्ड नहीं। JSON के लिए, सुनिश्चित करें फ़ाइल ट्रंकेट न हुई हो।
BF-E201Pro लाइसेंस इनवैलिड / एक्सपायर्ड चेकचेक करें Settings → Pro: चाबी दोबारा एंटर करें। ऑफ़लाइन चेक्स कैश होते हैं; री-वैलिडेट करने के लिए Whop के ज़रिए एक बार कनेक्ट करें।
BF-E202फ्री लिमिट रीच्ड (2,500 बुकमार्क)फ्री 2,500 है। डिलीट करें या अनलिमिटेड के लिए Pro लाइफटाइम v1 में अपग्रेड करें। एक्सपोर्ट हमेशा अवेलेबल है।

सपोर्ट टिप: एरर का Copy diagnostic क्लिक करने से कोड + कॉन्टेक्स्ट एक क्लिक में कॉपी होता है — अपने GitHub Discussion या ईमेल में पेस्ट करें।

रिडैक्टेड डायग्नॉस्टिक कॉपी करें — सपोर्ट को जो पेस्ट करें

ऐप में: Settings → Advanced (या Help → Diagnostics) → Copy diagnostic। ये ऐसा दिखता है — कोई वॉल्ट कंटेंट नहीं, कोई URL नहीं, कोई प्रॉम्प्ट नहीं:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

इसमें क्या होता है: ऐप वर्ज़न, ब्राउज़र, काउंट्स (बुकमार्क/डॉक्स/वेक्टर्स), स्टोरेज % + कोटा, P2P स्टेटस, AI स्टेटस, एरर काउंट्स और लास्ट BF-E कोड, बिल्ड हैश। IP का सॉल्टेड हैश इस्तेमाल करता है — हम IP कभी स्टोर नहीं करते। Privacy §3/§6 देखें।

अगर ऐप नहीं खुल रहा: ब्राउज़र + OS + रिप्रोड्यूस के स्टेप्स + स्क्रीन पर दिखने वाला BF-E* कोड शामिल करें। 90% टिकट्स के लिए ये काफ़ी है।
