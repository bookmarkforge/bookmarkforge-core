Pemecahan masalah — kebanyakan masalah dalam 30 detik

Vault terkunci / kata sandi salah

Kata sandi peka huruf besar-kecil dan spasi. Jika Anda ganti tata letak (mis. AZERTY→QWERTY) ketik perlahan. Setelah 5 kali gagal membuka, tunggu 1 menit. Jika Anda kehilangan kata sandi, gunakan frasa pemulihan 24 kata yang ditampilkan sekali saat pembuatan vault (BF-E101). Tanpa itu pemulihan mustahil secara desain — kami tidak punya pintu belakang.

Penyimpanan browser penuh

Kuota IndexedDB per-browser (biasanya 60–80% dari disk). Saat penuh, penyimpanan gagal dengan BF-E103. Perbaiki: Pengaturan → Penyimpanan → Kompak basis data lalu Bersihkan cache AI. Atau Ekspor cadangan (.bmf) → Hapus vektor lama. Periksa % penyimpanan di diagnostik — di atas 80% kami menampilkan spanduk.

Sinkron P2P tidak terhubung

Kedua perangkat harus daring dan terbuka pada saat bersamaan (WebRTC). Tanpa relay TURN secara bawaan — beberapa jaringan perusahaan memblokir P2P. Coba: keduanya di Wi-Fi yang sama → pasang QR → biarkan aplikasi tetap terbuka. Jika BF-E105, uji Bantuan → Diagnostik → P2P (WebRTC) — jika dikatakan tidak tersedia, browser/jaringan Anda memblokir WebRTC.

AI lokal (WebLLM) tidak berjalan

Memerlukan WebGPU + ~4 GB RAM bebas + lisensi Pro. Periksa Bantuan → Diagnostik → WebGPU/WebLLM. Jika BF-E106: perbarui Chrome/Edge ke terbaru, aktifkan chrome://flags/#enable-unsafe-webgpu, atau beralih ke Ollama (model apa pun yang Anda jalankan lokal — tanpa kunci API juga).

Pencarian atau impor lambat

Impor pertama membangun vektor HNSW — berat di CPU. Biarkan tab terbuka. Untuk 10k+ bookmark gunakan Pengaturan → Lanjutan → Paksa proses ulang. Jika tetap, Salin diagnostik menampilkan vectorIndexLoad dan latensi kueri.

Kode kesalahan BF-E* — salin kode, lompat ke perbaikan

Setiap kesalahan kritis menampilkan kode seperti BF-E101. Klik kode di aplikasi atau cari di sini.

Tips dukungan: mengklik Salin diagnostik pada kesalahan menyalin kode + konteks dalam satu klik — tempel di GitHub Discussion atau email Anda.

Salin diagnostik yang disensor — yang Anda tempel ke dukungan

Di aplikasi: Pengaturan → Lanjutan (atau Bantuan → Diagnostik) → Salin diagnostik. Tampilannya seperti ini — tanpa konten vault, tanpa URL, tanpa prompt:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Yang dikandungnya: versi aplikasi, browser, jumlah (bookmark/dokumen/vektor), % penyimpanan + kuota, status P2P, status AI, jumlah kesalahan & kode BF-E terakhir, hash build. Menggunakan hash ber-salt dari IP — kami tidak pernah menyimpan IP. Lihat Privasi §3/§6.

Jika Anda tidak bisa membuka aplikasi: sertakan browser + OS + langkah reproduksi + kode BF-E* di layar. Itu cukup untuk 90% tiket.
