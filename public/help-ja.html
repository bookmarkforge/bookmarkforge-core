トラブルシューティング — 多くは30秒で解決

Vaultがロック／パスワード不一致

パスワードは大文字小文字・空白を区別します。キーボードレイアウト（例：AZERTY→QWERTY）が変わっていないか確認し、ゆっくり入力してください。5回失敗後は1分待ってください。パスワードを忘れた場合は、Vault作成時に一度だけ表示される24語リカバリーフレーズを使用してください（BF-E101）。フレーズがない場合は設計上復元不可です（バックドアなし）。

ブラウザストレージ満杯

IndexedDBの容量はブラウザごと（通常はディスクの60〜80％）。満杯時はBF-E103が発生します。対処：設定 → ストレージ → DBを圧縮 → AIキャッシュを削除。またはバックアップをエクスポート (.bmf) → 古いベクトルを削除。診断のストレージ%が80%超だとバナーが表示されます。

P2P同期が接続しない

両端末がオンラインかつアンロックの同時状態である必要があります（WebRTC）。デフォルトではTURNリレーなしのため、一部企業ネットワークではP2Pが遮断されます。対処：同一Wi-FiでQRペアリング → アプリを開いたままにする。BF-E105の場合はヘルプ → 診断 → P2P（WebRTC）を確認。利用不可ならブラウザ／ネットワークがWebRTCをブロックしています。

ローカルAI（WebLLM）が動作しない

要件：WebGPU、空きRAM約4 GB、Proライセンス。ヘルプ → 診断 → WebGPU／WebLLMで確認。BF-E106の場合：Chrome/Edge最新版に更新、chrome://flags/#enable-unsafe-webgpuを有効化、またはOllamaへ切替（ローカル実行モデル、APIキー不要）。

検索・インポートが遅い

初回インポート時はHNSWベクトル生成（CPU負荷大）です。タブは開いたままにしてください。1万件超なら設定 → 詳細 → 強制再処理。改善しない場合は診断情報をコピーのvectorIndexLoad／クエリ遅延を確認してください。

エラーコード BF-E* — コードをコピーして修正へ

重大なエラーはBF-E101などのコードを表示します。アプリ内コードをクリックするか、ここで検索してください。

コード内容対処
BF-E101Vaultパスワード忘却／リカバリーフレーズ必須パスワードは復元できません。Vault作成時に24語フレーズを一度だけ表示しています。紙に書き留め、復旧に使用してください。フレーズなし＝復元不可です。この理由でチケットでは復旧できません。
BF-E102Vaultロック／パスワード不一致パスワードを正確に入力してください。5回失敗後は60秒待ってください。直近でパスワードを変更した場合は、以前のものを試すと解決することがあります（ローテーションは直前のsaltを保持）。
BF-E103ストレージ容量超過設定 → ストレージで DB圧縮＋AIキャッシュ削除を実行。必要なら.bmfバックアップをエクスポート。詳細は「トラブルシューティング §ストレージ」。
BF-E104IndexedDBブロック／プライベートブラウジングプライベート／シークレットモードやストレージ制限でIndexedDBがブロックされている可能性があります。通常ウィンドウで開いてください。ヘルプ → 診断 → ストレージを確認。
BF-E105P2P／WebRTC利用不可ブラウザ／ネットワークがWebRTCをブロックしています。他のブラウザ／ネットワークを試す、ファイアウォールの厳格度を下げる、またはリアルタイム同期ではなくエクスポート／インポートを使用してください。
BF-E106ローカルAI（WebLLM）がこの端末で動作不可要件：WebGPU + shader-f16 + 4 GB RAM + Pro。ブラウザを更新するか、Ollama／自身のキーでクラウドプロバイダーを使用してください。
BF-E107バックアップインポート失敗（パスワード誤り／ファイル破損）.bmf（暗号化済み）はエクスポート時のパスワード（Vaultパスワードではありません）が必要です。JSONはファイルが切断されていないか確認してください。
BF-E201Proライセンス無効／検証失敗設定 → Proでライセンスキーを再入力してください。オフライン時は検証結果をキャッシュしています。再接続するとWhopで再検証されます。
BF-E202Free上限到達（2,500ブックマーク）Freeは2,500件まで。削除するか、Pro v1ライフタイム（無制限）にアップグレードしてください。エクスポートは常時利用可能です。
