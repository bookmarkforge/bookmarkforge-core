문제 해결 — 30초 안에 대부분 해결

볼트 잠김 / 잘못된 비밀번호

비밀번호는 대소문자와 공백을 구분합니다. 레이아웃을 바꿨다면 (예: AZERTY→QWERTY) 천천히 다시 입력하세요. 5회 실패 잠금 해제 후 1분 기다리세요. 비밀번호를 잃었다면 볼트 생성 시 한 번 보여준 24단어 복구 문구를 사용하세요 (BF-E101). 없으면 설계상 복구 불가능 — 백도어가 없습니다.

브라우저 저장소 가득 참

IndexedDB 할당량은 브라우저별 (보통 디스크의 60–80%). 가득 차면 저장이 BF-E103으로 실패합니다. 해결: Settings → Storage → Compact database 후 Clear AI cache. 또는 Export backup (.bmf) → Delete old vectors. 진단의 storage % 확인 — 80% 초과 시 배너를 보여줍니다.

P2P 동기화 연결 안 됨

두 기기 모두 동시에 온라인이고 잠금 해제 상태여야 합니다 (WebRTC). 기본적으로 TURN 릴레이 없음 — 일부 기업 네트워크는 P2P를 차단합니다. 시도: 둘 다 같은 Wi-Fi → QR 페어링 → 앱 열어두기. BF-E105라면 Help → Diagnostics → P2P (WebRTC) 테스트 — 사용 불가라고 나오면 브라우저/네트워크가 WebRTC를 차단합니다.

로컬 AI (WebLLM) 실행 안 됨

WebGPU + ~4 GB 여유 RAM + Pro 라이선스 필요. Help → Diagnostics → WebGPU/WebLLM 확인. BF-E106라면: Chrome/Edge를 최신으로 업데이트, chrome://flags/#enable-unsafe-webgpu 활성화, 또는 Ollama로 전환 (로컬에서 실행하는 어떤 모델든 — API 키 불필요).

검색 또는 가져오기 느림

첫 가져오기는 HNSW 벡터를 빌드합니다 — CPU 집약적. 탭을 열어두세요. 10k+ 북마크라면 Settings → Advanced → Force reprocess. 계속되면 Copy diagnostic이 vectorIndexLoad와 쿼리 지연을 보여줍니다.

오류 코드 BF-E* — 코드를 복사하고 수정으로 이동

모든 치명적 오류는 BF-E101 같은 코드를 보여줍니다. 앱에서 코드를 클릭하거나 여기서 검색하세요.

축소된 진단 복사 — 지원에 붙여넣는 내용

앱에서: Settings → Advanced (또는 Help → Diagnostics) → Copy diagnostic. 이렇게 생겼습니다 — 볼트 콘텐츠, URL, 프롬프트 없음:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

포함 내용: 앱 버전, 브라우저, 개수 (북마크/문서/벡터), 저장소 % + 할당량, P2P 상태, AI 상태, 오류 개수 & 마지막 BF-E 코드, 빌드 해시. IP의 salted hash 사용 — IP를 절대 저장하지 않습니다. Privacy §3/§6 참조.

앱을 열 수 없다면: 브라우저 + OS + 재현 단계 + 화면의 BF-E* 코드를 포함하세요. 티켓의 90%는 이것으로 충분합니다.
