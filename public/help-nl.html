Probleemoplossing — de meeste problemen in 30 seconden

Kluis vergrendeld / verkeerd wachtwoord

Wachtwoorden zijn hoofdletter- en spatiergevoelig. Als je van indeling wisselde (bijv. AZERTY→QWERTY), typ dan langzaam. Na 5 mislukte ontgrendelingen wacht je 1 minuut. Als je het wachtwoord kwijt bent, gebruik dan de 24-woord herstelzin die eenmaal bij het aanmaken van de kluis getoond wordt (BF-E101). Zonder hem is herstel onmogelijk by design — wij hebben geen achterdeur.

Browseropslag vol

IndexedDB-quotum is per browser (doorgaans 60–80% van de schijf). Als hij vol is, mislukken opslagen met BF-E103. Oplossing: Instellingen → Opslag → Database comprimeren daarna AI-cache wissen. Of Back-up exporteren (.bmf) → Oude vectoren verwijderen. Controleer opslag-% in diagnose — boven 80% tonen we een banner.

P2P-sync maakt geen verbinding

Beide apparaten moeten tegelijk online en ontgrendeld zijn (WebRTC). Geen TURN-relay standaard — sommige bedrijfsnetwerken blokkeren P2P. Probeer: beide op hetzelfde Wi-Fi → QR koppelen → app open houden. Bij BF-E105, test Hulp → Diagnose → P2P (WebRTC) — als hij zegt onbeschikbaar, blokkeert je browser/netwerk WebRTC.

Lokale AI (WebLLM) draait niet

Vereist WebGPU + ~4 GB vrij RAM + Pro-licentie. Controleer Hulp → Diagnose → WebGPU/WebLLM. Bij BF-E106: update Chrome/Edge naar de nieuwste versie, zet chrome://flags/#enable-unsafe-webgpu aan, of schakel over naar Ollama (elk model dat je lokaal draait — geen API-sleutel nodig).

Langzame zoekopdracht of import

De eerste import bouwt HNSW-vectoren — CPU-zwaar. Houd het tabblad open. Voor 10k+ bladwijzers gebruik je Instellingen → Geavanceerd → Geforceerd herverwerken. Als het aanhoudt, toont Diagnose kopiëren vectorIndexLoad en querylatentie.

Foutcodes BF-E* — kopieer de code, spring naar de oplossing

Elke kritieke fout toont een code zoals BF-E101. Klik op de code in de app of zoek hem hier.

CodeBetekenisOplossing
BF-E101Kluiswachtwoord vergeten / herstelzin vereistWij kunnen wachtwoorden niet herstellen. Bij het aanmaken van de kluis tonen we een 24-woord zin eenmaal — schrijf hem op papier. Gebruik hem om te resetten. Geen zin = kluis onherstelbaar. Geen ticket herstelt hem.
BF-E102Kluis vergrendeld / verkeerd wachtwoordTyp wachtwoord exact opnieuw. Na 5 mislukkingen wacht 60s. Als je het wachtwoord recent roteerde, probeer dan het vorige — bij rotatie blijft de laatste salt behouden voor rollback.
BF-E103Opslagquotum overschredenGa naar Instellingen → Opslag: DB comprimeren + AI-cache wissen. Exporteer .bmf-back-up indien nodig. Zie Probleemoplossing §Opslag.
BF-E104IndexedDB geblokkeerd / privé browsenIndexedDB is geblokkeerd in privé/incognito of door opslagbeleid. Gebruik een normaal venster. Controleer Hulp → Diagnose → Opslag.
BF-E105P2P / WebRTC onbeschikbaarBrowser of netwerk blokkeert WebRTC. Probeer een andere browser/netwerk, schakel strenge firewall uit, of gebruik Exporteren/Importeren in plaats van live sync.
BF-E106Lokale AI (WebLLM) kan niet draaien op dit apparaatVereist WebGPU + shader-f16 + 4 GB RAM + Pro. Update browser, of gebruik Ollama / cloudprovider met je eigen sleutel.
BF-E107Back-up import mislukt (verkeerd wachtwoord / corrupt bestand)Voor .bmf (versleuteld) heb je het exportwachtwoord nodig, niet het kluiswachtwoord. Voor JSON, controleer of het bestand niet is afgebroken.
BF-E201Pro-licentie ongeldig / verlopenControleer Instellingen → Pro: voer sleutel opnieuw in. Offline controles cachen; verbind eenmaal om opnieuw te valideren via Whop.
BF-E202Gratis limiet bereikt (2.500 bladwijzers)Gratis is 2.500. Verwijder of upgrade naar Pro Lifetime v1 voor onbeperkt. Exporteren is altijd beschikbaar.

Support-tip: klikken op Diagnose kopiëren van de fout kopieert code + context in één klik — plak hem in je GitHub-discussie of e-mail.

Een geredigeerde diagnose kopiëren — wat je aan support plakt

In de app: Instellingen → Geavanceerd (of Hulp → Diagnose) → Diagnose kopiëren. Het ziet er zo uit — geen kluisinhoud, geen URL's, geen prompts:

BookmarkForge v1.0.0 | Chrome 126 | Kluis: 847 bladwijzers, 12 docs Opslag: 42% (IndexedDB OK) | Laatste back-up: 2 dagen geleden (.bmf versleuteld) P2P: niet verbonden | Sync: nooit | Lokale AI: WebLLM niet geladen Fouten: 0 laatste 7d | BF-E: geen | Build: a1b2c3d

Wat het bevat: appversie, browser, aantallen (bladwijzers/docs/vectoren), opslag-% + quotum, P2P-status, AI-status, foutenaantallen & laatste BF-E-code, build-hash. Gebruikt een gehashte IP met salt — we slaan nooit een IP op. Zie Privacy §3/§6.

Als je de app niet kunt openen: voeg browser + OS + stappen om te reproduceren + de BF-E*-code op het scherm toe. Dat is genoeg voor 90% van de tickets.
