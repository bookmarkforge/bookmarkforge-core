Støtte-SLA — hvor raskt vi svarer

Én vedlikeholder. Hvelvet er kryptert — vi spør aldri om hvelvpassordet eller den 24-ords gjenopprettingsfrasen din. Støtten er best-effort for Free og forpliktende for betalte nivåer.

FreeSelvhjelp: dette Hjelpesenteret + GitHub DiscussionsBeste innsats (fellesskapet)Søk etter BF-E*-koden nedenfor + kopier diagnostikken (§Diagnostikk) før du poster

Vi kan ikke se bokmerkene, notatene, URL-ene eller oppfordringene dine. Ta bare med diagnostikken nedenfor — den inneholder antall og versjoner, aldri innhold fra hvelvet.

Feilsøking — de fleste problemer på 30 sekunder

Hvelvet er låst / feil passord

Passord skiller mellom store og små bokstaver, og mellomrom teller. Har du byttet tastaturlayout (f.eks. AZERTY→QWERTY), skriver du sakte. Etter 5 mislykkede opplåsinger venter du 1 minutt. Har du mistet passordet, bruker du den 24-ords gjenopprettingsfrasen som vises én gang ved opprettelse av hvelvet (BF-E101). Uten den er gjenoppretting umulig med vilje — vi har ingen bakvei.

Nettleserens lager er fullt

IndexedDB-kvoten gjelder per nettleser (vanligvis 60–80 % av disken). Når lageret er fullt, feiler lagring med BF-E103. Løsning: Settings → Storage → Compact database og deretter Clear AI cache. Eller Export backup (.bmf) → Delete old vectors. Sjekk lager % i diagnostikken — over 80 % viser vi et banner.

P2P-synkroniseringen kobler ikke

Begge enhetene må være pålogget og ulåste samtidig (WebRTC). Ingen TURN-relay som standard — enkelte bedriftsnettverk blokkerer P2P. Prøv: begge på samme Wi-Fi → QR-paring → hold appen åpen. Får du BF-E105, test Help → Diagnostics → P2P (WebRTC) — står det utilgjengelig, blokkerer nettleseren eller nettverket ditt WebRTC.

Lokal KI (WebLLM) kjører ikke

Krever WebGPU + ~4 GB ledig RAM + Pro-lisens. Sjekk Help → Diagnostics → WebGPU/WebLLM. Får du BF-E106: oppdater Chrome/Edge til nyeste versjon, slå på chrome://flags/#enable-unsafe-webgpu, eller bytt til Ollama (hvilken som helst modell du kjører lokalt — du trenger heller ikke API-nøkkel).

Langsomt søk eller import

Første import bygger HNSW-vektorer — krever mye CPU. Hold fanen åpen. For 10k+ bokmerker bruker du Settings → Advanced → Force reprocess. Vedvarer problemet, viser Copy diagnostic vectorIndexLoad og spørringsforsinkelsen.

Feilkoder BF-E* — kopier koden, hopp til løsningen

Alle kritiske feil viser en kode som BF-E101. Klikk på koden i appen, eller søk etter den her.

KodeBetydningLøsning
BF-E101Hvelvpassord glemt / frøfrase krevesVi kan ikke gjenopprette passord. Ved opprettelse av hvelvet viser vi en 24-ords frase én gang — skriv den på papir. Bruk den til å tilbakestille. Uten frase er hvelvet uopprettelig. Ingen billett kan gjenopprette det.
BF-E102Hvelvet er låst / feil passordSkriv passordet nøyaktig. Etter 5 feil venter du 60 s. Har du byttet passord nylig, prøv det forrige — bytting beholder siste salt for tilbakerulling.
BF-E103Lagerkvoten er overskredetGå til Settings → Storage: Compact DB + Clear AI cache. Eksporter en .bmf-sikkerhetskopi ved behov. Se Feilsøking §Lager.
BF-E104IndexedDB er blokkert / privatmodus i nettleserenIndexedDB er blokkert i privat-/inkognitomodus eller av lagerpolicyen. Bruk et vanlig vindu. Sjekk Help → Diagnostics → Storage.
BF-E105P2P / WebRTC utilgjengeligNettleseren eller nettverket blokkerer WebRTC. Prøv en annen nettleser eller et annet nettverk, slå av streng brannmur, eller bruk Eksport/Import i stedet for direkte synkronisering.
BF-E106Lokal KI (WebLLM) kan ikke kjøres på denne enhetenKrever WebGPU + shader-f16 + 4 GB RAM + Pro. Oppdater nettleseren, eller bruk Ollama / skyleverandør med din egen nøkkel.
BF-E107Import av sikkerhetskopi mislyktes (feil passord / ødelagt fil)For .bmf (kryptert) trenger du eksportpassordet, ikke hvelvpassordet. For JSON må du kontrollere at filen ikke er avkortet.
BF-E201Pro-lisensen er ugyldig / utløpt kontrollSjekk Settings → Pro: skriv inn nøkkelen på nytt. Offlinekontroller mellomlagres; koble til én gang for å validere på nytt via Whop.
BF-E202Gratisgrensen er nådd (2,500 bokmerker)Gratis er 2,500. Slett bokmerker eller oppgrader til Pro Lifetime v1 for ubegrenset. Eksport er alltid tilgjengelig.

Støttetips: å klikke på feilens Copy diagnostic kopierer kode + kontekst med ett klikk — lim den inn i GitHub Discussion eller e-posten din.

Kopier en redigert diagnostikk — dette sender du til støtten

I appen: Settings → Advanced (eller Help → Diagnostics) → Copy diagnostic. Den ser slik ut — intet innhold fra hvelvet, ingen URL-er, ingen oppfordringer:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Innhold: appversjon, nettleser, antall (bokmerker/dokumenter/vektorer), lager % + kvote, P2P-status, KI-status, feilantall og siste BF-E-kode, bygghash. Bruker en saltet hash av IP-en — vi lagrer aldri IP. Se Personvern §3/§6.

Får du ikke åpnet appen: ta med nettleser + operativsystem + trinnene for å reprodusere + BF-E*-koden på skjermen. Det er nok for 90 % av billettene.
