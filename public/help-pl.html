Rozwiązywanie problemów — większość kwestii w 30 sekund

Sejf zablokowany / złe hasło

W hasłach znaczenie mają wielkość liter i spacje. Jeśli zmieniłeś układ klawiatury (np. AZERTY→QWERTY), wpisz go powoli. Po 5 nieudanych odblokowaniach odczekaj 1 minutę. Jeśli zgubiłeś hasło, użyj 24-słowowej frazy odzyskiwania pokazanej raz przy tworzeniu sejfu (BF-E101). Bez niej odzyskanie jest niemożliwe z założenia — nie mamy żadnego wejścia awaryjnego.

Pełna pamięć przeglądarki

Limit IndexedDB jest przeglądarkowy (zwykle 60–80% dysku). Gdy się zapełni, zapisywanie kończy się błędem BF-E103. Rozwiązanie: Settings → Storage → Compact database, a potem Clear AI cache. Albo Export backup (.bmf) → Delete old vectors. Sprawdź zużycie pamięci w diagnostyce — powyżej 80% pokazujemy baner.

Synchronizacja P2P nie łączy się

Oba urządzenia muszą być jednocześnie online i odblokowane (WebRTC). Domyślnie brak przekaźnika TURN — niektóre sieci firmowe blokują P2P. Spróbuj: oba w tej samej sieci Wi-Fi → sparuj kodem QR → nie zamykaj aplikacji. Jeśli BF-E105, sprawdź Help → Diagnostics → P2P (WebRTC) — jeśli napisze „niedostępne”, Twoja przeglądarka albo sieć blokuje WebRTC.

Lokalne AI (WebLLM) nie działa

Wymaga WebGPU + ok. 4 GB wolnej pamięci RAM + licencji Pro. Sprawdź Help → Diagnostics → WebGPU/WebLLM. Jeśli BF-E106: zaktualizuj Chrome/Edge do najnowszej wersji, włącz chrome://flags/#enable-unsafe-webgpu albo przełącz się na Ollama (dowolny model uruchamiany lokalnie — klucz API też nie jest potrzebny).

Wolne wyszukiwanie lub import

Pierwszy import buduje wektory HNSW — mocno obciąża CPU. Zostaw kartę otwartą. Przy 10k+ zakładek użyj Settings → Advanced → Force reprocess. Jeśli problem trwa, Copy diagnostic pokazuje vectorIndexLoad i opóźnienie zapytań.

Skopiuj zanonimizowaną diagnostykę — co wklejasz do wsparcia

W aplikacji: Settings → Advanced (albo Help → Diagnostics) → Copy diagnostic. Wygląda to tak — bez treści sejfu, bez adresów URL, bez poleceń:

BookmarkForge v1.0.0 | Chrome 126 | Sejf: 847 zakładek, 12 dokumentów Pamięć: 42% (IndexedDB OK) | Ostatnia kopia: 2 dni temu (.bmf zaszyfrowany) P2P: niepołączone | Synchronizacja: nigdy | Lokalne AI: WebLLM nie wczytany Błędy: 0 w ostatnich 7 dni | BF-E: brak | Kompilacja: a1b2c3d

Co zawiera: wersja aplikacji, przeglądarka, liczniki (zakładki/dokumenty/wektory), wykorzystanie pamięci % + limit, status P2P, status AI, liczba błędów i ostatni kod BF-E, hash kompilacji. Używa zsolonego hasha adresu IP — nigdy nie zapisujemy IP. Zob. Prywatność §3/§6.

Jeśli nie możesz otworzyć aplikacji: podaj przeglądarkę, system operacyjny, kroki do odtworzenia i kod BF-E* widoczny na ekranie. To wystarczy w 90% zgłoszeń.
