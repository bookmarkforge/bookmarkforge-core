Solução de problemas — a maioria dos casos em 30 segundos

Cofre bloqueado / senha incorreta

Senhas diferenciam maiúsculas/minúsculas e espaços em branco. Se você mudou o layout (ex.: AZERTY→QWERTY), redigite devagar. Após 5 desbloqueios falhos, aguarde 1 minuto. Se perdeu a senha, use a frase de recuperação de 24 palavras exibida uma única vez na criação do cofre (BF-E101). Sem ela a recuperação é impossível por design — não temos backdoor.

Armazenamento do navegador cheio

A cota do IndexedDB é por navegador (tipicamente 60–80% do disco). Quando cheia, salvamentos falham com BF-E103. Correção: Configurações → Armazenamento → Compactar banco de dados depois Limpar cache de IA. Ou Exportar backup (.bmf) → Excluir vetores antigos. Verifique o % de armazenamento no diagnóstico — acima de 80% mostramos um banner.

Sincronização P2P não conecta

Ambos os dispositivos devem estar online e desbloqueados ao mesmo tempo (WebRTC). Sem relay TURN por padrão — algumas redes corporativas bloqueiam P2P. Tente: ambos no mesmo Wi-Fi → pareamento por QR → mantenha o app aberto. Se BF-E105, teste Ajuda → Diagnósticos → P2P (WebRTC) — se disser indisponível, seu navegador/rede bloqueia WebRTC.

IA local (WebLLM) não está rodando

Requer WebGPU + ~4 GB de RAM livre + licença Pro. Verifique Ajuda → Diagnósticos → WebGPU/WebLLM. Se BF-E106: atualize Chrome/Edge para a versão mais recente, ative chrome://flags/#enable-unsafe-webgpu ou mude para Ollama (qualquer modelo que você rode localmente — também não precisa de chave de API).

Busca ou importação lenta

A primeira importação constrói vetores HNSW — pesado para a CPU. Mantenha a aba aberta. Para 10k+ bookmarks use Configurações → Avançado → Forçar reprocessamento. Se persistir, Copiar diagnóstico mostra vectorIndexLoad e a latência da consulta.

Códigos de erro BF-E* — copie o código, vá para a correção

Todo erro crítico exibe um código como BF-E101. Clique no código no app ou pesquise-o aqui.

CódigoSignificadoCorreção
BF-E101Senha do cofre esquecida / frase semente necessáriaNão conseguimos recuperar senhas. Na criação do cofre exibimos uma frase de 24 palavras uma única vez — anote-a no papel. Use-a para redefinir. Sem frase = cofre irrecuperável. Nenhum ticket a recuperará.
BF-E102Cofre bloqueado / senha incorretaRedigite a senha exatamente. Após 5 falhas aguarde 60s. Se você rotacionou a senha recentemente, tente a anterior — a rotação mantém o último salt para rollback.
BF-E103Cota de armazenamento excedidaVá para Configurações → Armazenamento: Compactar BD + Limpar cache de IA. Exporte backup .bmf se necessário. Veja Solução de problemas §Armazenamento.
BF-E104IndexedDB bloqueado / navegação privativaO IndexedDB é bloqueado em modo privativo/anônimo ou por política de armazenamento. Use uma janela normal. Verifique Ajuda → Diagnósticos → Armazenamento.
BF-E105P2P / WebRTC indisponívelO navegador ou a rede bloqueia WebRTC. Tente outro navegador/rede, desative firewall rígido ou use Exportar/Importar em vez de sincronização ao vivo.
BF-E106IA local (WebLLM) não pode rodar neste dispositivoPrecisa de WebGPU + shader-f16 + 4 GB de RAM + Pro. Atualize o navegador ou use Ollama / provedor na nuvem com sua própria chave.
BF-E107Importação de backup falhou (senha incorreta / arquivo corrompido)Para .bmf (criptografado) você precisa da senha de exportação, não da senha do cofre. Para JSON, verifique se o arquivo não foi truncado.
BF-E201Licença Pro inválida / verificação expiradaVerifique Configurações → Pro: reinsira a chave. Verificações offline usam cache; reconecte uma vez para revalidar via Whop.
BF-E202Limite do Free atingido (2.500 bookmarks)O Free é 2.500. Exclua ou atualize para o Pro Lifetime v1 para ilimitado. A exportação está sempre disponível.

Dica de suporte: clicar em Copiar diagnóstico do erro copia código + contexto em um clique — cole na sua Discussão no GitHub ou e-mail.

Copiar um diagnóstico redigido — o que você cola no suporte

No app: Configurações → Avançado (ou Ajuda → Diagnósticos) → Copiar diagnóstico. É assim que parece — sem conteúdo do cofre, sem URLs, sem prompts:

BookmarkForge v1.0.0 | Chrome 126 | Cofre: 847 bookmarks, 12 docs Armazenamento: 42% (IndexedDB OK) | Último backup: há 2 dias (.bmf criptografado) P2P: não conectado | Sync: nunca | IA local: WebLLM não carregado Erros: 0 nos últimos 7d | BF-E: nenhum | Build: a1b2c3d

O que ele contém: versão do app, navegador, contagens (bookmarks/docs/vetores), % de armazenamento + cota, status do P2P, status da IA, contagens de erro e último código BF-E, hash do build. Usa um hash com salt do IP — nunca armazenamos IP. Veja Privacidade §3/§6.

Se você não consegue abrir o app: inclua navegador + SO + passos para reproduzir + o código BF-E* na tela. Isso basta para 90% dos tickets.
