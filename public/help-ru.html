Устранение неполадок — большинство проблем за 30 секунд

Хранилище заблокировано / неверный пароль

Пароли чувствительны к регистру и пробелам. Если вы сменили раскладку (например AZERTY→QWERTY), вводите медленно. После 5 неудачных попыток подождите 1 минуту. Если потеряли пароль, используйте 24-словную фразу восстановления, показанную один раз при создании хранилища (BF-E101). Без неё восстановление невозможно по дизайну — у нас нет бэкдора.

Хранилище браузера заполнено

Квота IndexedDB зависит от браузера (обычно 60–80% диска). Когда она заполнена, сохранения падают с BF-E103. Исправление: Settings → Storage → Compact database, затем Clear AI cache. Или Export backup (.bmf) → Delete old vectors. Проверьте % хранилища в диагностике — выше 80% мы показываем баннер.

P2P-синхронизация не подключается

Оба устройства должны быть онлайн и разблокированы одновременно (WebRTC). TURN-реле по умолчанию нет — некоторые корпоративные сети блокируют P2P. Попробуйте: оба в одной Wi-Fi → связать по QR → держать приложение открытым. Если BF-E105, проверьте Help → Diagnostics → P2P (WebRTC) — если недоступно, ваш браузер/сеть блокирует WebRTC.

Локальный AI (WebLLM) не запускается

Требуется WebGPU + ~4 ГБ свободной RAM + лицензия Pro. Проверьте Help → Diagnostics → WebGPU/WebLLM. Если BF-E106: обновите Chrome/Edge до последней версии, включите chrome://flags/#enable-unsafe-webgpu или переключитесь на Ollama (любая модель, которую вы запускаете локально — API-ключ тоже не нужен).

Медленный поиск или импорт

Первый импорт строит HNSW-векторы — нагрузка на CPU. Держите вкладку открытой. Для 10k+ закладок используйте Settings → Advanced → Force reprocess. Если сохраняется, Copy diagnostic покажет vectorIndexLoad и задержку запроса.

Коды ошибок BF-E* — скопируйте код, перейдите к исправлению

Каждая критическая ошибка показывает код вроде BF-E101. Нажмите код в приложении или найдите его здесь.

КодЗначениеИсправление
BF-E101Пароль хранилища забыт / требуется фраза восстановленияМы не можем восстановить пароли. При создании хранилища мы один раз показываем 24-словную фразу — запишите её на бумаге. Используйте её для сброса. Нет фразы = хранилище невосстановимо. Никакой тикет его не восстановит.
BF-E102Хранилище заблокировано / неверный парольВведите пароль точно. После 5 неудач подождите 60 с. Если недавно меняли пароль, попробуйте предыдущий — при ротации сохраняется последняя соль для отката.
BF-E103Превышена квота хранилищаПерейдите в Settings → Storage: Compact DB + Clear AI cache. Экспортируйте резервную копию .bmf при необходимости. См. «Устранение неполадок §Хранилище».
BF-E104IndexedDB заблокирован / приватный просмотрIndexedDB заблокирован в приватном/инкогнито-режиме или политикой хранения. Используйте обычное окно. Проверьте Help → Diagnostics → Storage.
BF-E105P2P / WebRTC недоступныБраузер или сеть блокирует WebRTC. Попробуйте другой браузер/сеть, отключите строгий файрвол или используйте Экспорт/Импорт вместо живой синхронизации.
BF-E106Локальный AI (WebLLM) не может работать на этом устройствеНужны WebGPU + shader-f16 + 4 ГБ RAM + Pro. Обновите браузер или используйте Ollama / облачного провайдера со своим ключом.
BF-E107Импорт резервной копии не удался (неверный пароль / повреждённый файл)Для .bmf (зашифрованного) нужен пароль экспорта, а не пароль хранилища. Для JSON убедитесь, что файл не был обрезан.
BF-E201Лицензия Pro недействительна / проверка просроченаПроверьте Settings → Pro: введите ключ заново. Оффлайн-проверки кэшируются; подключитесь один раз для повторной проверки через Whop.
BF-E202Достигнут бесплатный лимит (2 500 закладок)Free — 2 500. Удалите или обновитесь до Pro Lifetime v1 для безлимита. Экспорт всегда доступен.

Совет поддержки: нажатие Copy diagnostic у ошибки копирует код + контекст одним кликом — вставьте в обсуждение GitHub или email.

Скопировать обезличенную диагностику — что вы вставляете в поддержку

В приложении: Settings → Advanced (или Help → Diagnostics) → Copy diagnostic. Выглядит так — никакого содержимого хранилища, URL, промптов:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Что содержит: версия приложения, браузер, количества (закладки/документы/векторы), % хранилища + квота, статус P2P, статус AI, количество ошибок и последний код BF-E, хэш сборки. Использует солёный хэш IP — мы никогда не храним IP. См. Конфиденциальность §3/§6.

Если не можете открыть приложение: укажите браузер + ОС + шаги воспроизведения + код BF-E* на экране. Этого достаточно для 90% тикетов.
