แก้ปัญหา — ปัญหาส่วนใหญ่ใน 30 วินาที

vault ล็อก / รหัสผ่านผิด

รหัสผ่านคำนึงถึงตัวพิมพ์ใหญ่เล็กและเว้นวรรค หากคุณเปลี่ยนเลย์เอาต์ (เช่น AZERTY→QWERTY) พิมพ์ใหม่ช้าๆ หลังปลดล็อกผิด 5 ครั้ง รอ 1 นาที หากคุณทำรหัสผ่านหาย ใช้ วลีกู้คืน 24 คำ ที่แสดงครั้งเดียวเมื่อสร้าง vault (BF-E101) ไม่มีวลีนั้นกู้คืนไม่ได้โดยการออกแบบ — เราไม่มี backdoor

พื้นที่จัดเก็บเบราว์เซอร์เต็ม

โควตา IndexedDB แยกตามเบราว์เซอร์ (โดยทั่วไป 60–80% ของดิสก์) เมื่อเต็ม การบันทึกจะล้มเหลวด้วย BF-E103 แก้ไข: Settings → Storage → Compact database แล้ว Clear AI cache หรือ Export backup (.bmf) → Delete old vectors ตรวจสอบ % พื้นที่จัดเก็บในการวินิจฉัย — เกิน 80% เราแสดงแบนเนอร์

P2P sync ไม่เชื่อมต่อ

ทั้งสองอุปกรณ์ต้อง ออนไลน์และปลดล็อก ในเวลาเดียวกัน (WebRTC) ไม่มี TURN relay โดยค่าเริ่มต้น — เครือข่ายองค์กรบางแห่งบล็อก P2P ลอง: ทั้งสองเครื่องบน Wi-Fi เดียวกัน → จับคู่ QR → เก็บแอปเปิด ถ้า BF-E105 ทดสอบ Help → Diagnostics → P2P (WebRTC) — ถ้าบอกว่าไม่พร้อมใช้งาน เบราว์เซอร์/เครือข่ายของคุณบล็อก WebRTC

AI ในเครื่อง (WebLLM) ไม่ทำงาน

ต้องใช้ WebGPU + RAM ว่าง ~4 GB + ใบอนุญาต Pro ตรวจสอบ Help → Diagnostics → WebGPU/WebLLM ถ้า BF-E106: อัปเดต Chrome/Edge เป็นเวอร์ชันล่าสุด เปิด chrome://flags/#enable-unsafe-webgpu หรือสลับไป Ollama (โมเดลใดก็ได้ที่คุณรันในเครื่อง — ไม่ต้องใช้ API key เช่นกัน)

การค้นหาหรือการนำเข้าช้า

การนำเข้าครั้งแรกสร้างเวกเตอร์ HNSW — ใช้ CPU หนัก เก็บแท็บเปิดไว้ สำหรับ 10k+ บุ๊กมาร์กใช้ Settings → Advanced → Force reprocess ถ้ายังคงอยู่ Copy diagnostic แสดง vectorIndexLoad และความหน่วงของคำค้น

รหัสข้อผิดพลาด BF-E* — คัดลอกรหัส แล้วกระโดดไปยังวิธีแก้

ข้อผิดพลาดวิกฤตทุกครั้งแสดงรหัสเช่น BF-E101 คลิกรหัสในแอปหรือค้นหามันที่นี่

รหัสความหมายวิธีแก้
BF-E101ลืมรหัสผ่าน vault / ต้องใช้วลี seedเราไม่สามารถกู้คืนรหัสผ่าน เมื่อสร้าง vault เราแสดง วลี 24 คำครั้งเดียว — เขียนลงกระดาษ ใช้มันเพื่อรีเซ็ต ไม่มีวลี = vault กู้คืนไม่ได้ ไม่มี ticket ใดกู้คืนได้
BF-E102vault ล็อก / รหัสผ่านผิดพิมพ์รหัสผ่านให้ถูกต้อง หลังล้มเหลว 5 ครั้งรอ 60 วินาที หากคุณเปลี่ยนรหัสผ่านเมื่อเร็วๆ นี้ ลองรหัสผ่านก่อนหน้า — การหมุนเวียนเก็บ salt ล่าสุดไว้สำหรับ rollback
BF-E103เกินโควตาพื้นที่จัดเก็บไปที่ Settings → Storage: Compact DB + Clear AI cache ส่งออก .bmf backup หากจำเป็น ดู Troubleshooting §Storage
BF-E104IndexedDB ถูกบล็อก / การท่องเว็บแบบส่วนตัวIndexedDB ถูกบล็อกในโหมดส่วนตัว/incognito หรือโดยนโยบายพื้นที่จัดเก็บ ใช้หน้าต่างปกติ ตรวจสอบ Help → Diagnostics → Storage
BF-E105P2P / WebRTC ไม่พร้อมใช้งานเบราว์เซอร์หรือเครือข่ายบล็อก WebRTC ลองเบราว์เซอร์/เครือข่ายอื่น ปิดไฟร์วอลล์เข้มงวด หรือใช้ Export/Import แทน live sync
BF-E106AI ในเครื่อง (WebLLM) รันบนอุปกรณ์นี้ไม่ได้ต้องใช้ WebGPU + shader-f16 + RAM 4 GB + Pro อัปเดตเบราว์เซอร์ หรือใช้ Ollama / ผู้ให้บริการคลาวด์ด้วยกุญแจของคุณเอง
BF-E107การนำเข้าแบ็กอัพล้มเหลว (รหัสผ่านผิด / ไฟล์เสียหาย)สำหรับ .bmf (เข้ารหัส) คุณต้องใช้รหัสผ่านส่งออก ไม่ใช่รหัสผ่าน vault สำหรับ JSON ตรวจสอบว่าไฟล์ไม่ถูกตัดทอน
BF-E201ใบอนุญาต Pro ไม่ถูกต้อง / หมดอายุตรวจสอบ Settings → Pro: ใส่กุญแจใหม่ การตรวจสอบออฟไลน์แคช; เชื่อมต่ออีกครั้งเพื่อ re-validate ผ่าน Whop
BF-E202ถึงขีดจำกัด Free (2,500 บุ๊กมาร์ก)ฟรีคือ 2,500 ลบหรืออัปเกรดเป็น Pro Lifetime v1 เพื่อไม่จำกัด การส่งออกใช้ได้เสมอ

เคล็ดลับการสนับสนุน: คลิก Copy diagnostic ของข้อผิดพลาดจะคัดลอกรหัส + บริบทในคลิกเดียว — วางใน GitHub Discussion หรืออีเมลของคุณ

คัดลอกการวินิจฉัยที่ปกปิด — สิ่งที่คุณวางให้การสนับสนุน

ในแอป: Settings → Advanced (หรือ Help → Diagnostics) → Copy diagnostic หน้าตาแบบนี้ — ไม่มีเนื้อหา vault ไม่มี URL ไม่มีพรอมต์:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

สิ่งที่มันมี: เวอร์ชันแอป เบราว์เซอร์ จำนวน (บุ๊กมาร์ก/เอกสาร/เวกเตอร์) % พื้นที่จัดเก็บ + โควตา สถานะ P2P สถานะ AI จำนวนข้อผิดพลาด & รหัส BF-E ล่าสุด build hash ใช้ salted hash ของ IP — เราไม่เคยเก็บ IP ดู Privacy §3/§6

หากคุณเปิดแอปไม่ได้: รวมเบราว์เซอร์ + OS + ขั้นตอนการสร้างข้อผิดพลาด + รหัส BF-E* บนหน้าจอ นั่นเพียงพอสำหรับ 90% ของ tickets
