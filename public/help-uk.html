Усунення неполадок — більшість проблем за 30 секунд

Сховище замкнене / неправильний пароль

Паролі чутливі до регістру та пробілів. Якщо ви змінили розкладку (напр. AZERTY→QWERTY), вводьте повільно. Після 5 невдалих спроб відмикання зачекайте 1 хвилину. Якщо ви втратили пароль, використайте 24-словну фразу відновлення, показану один раз при створенні сховища (BF-E101). Без неї відновлення неможливе за задумом — у нас немає чорного ходу.

Сховище браузера заповнене

Квота IndexedDB залежить від браузера (зазвичай 60–80% диска). Коли заповнено, збереження завершуються помилкою BF-E103. Виправлення: Налаштування → Сховище → Стиснути базу даних, потім Очистити кеш ШІ. Або Експортувати резервну копію (.bmf) → Видалити старі вектори. Перевірте % сховища в діагностиці — вище 80% ми показуємо банер.

P2P-синхронізація не підключається

Обидва пристрої мають бути онлайн і відімкнені одночасно (WebRTC). Ретранслятора TURN за замовчуванням немає — деякі корпоративні мережі блокують P2P. Спробуйте: обидва в одній Wi-Fi → з’єднання через QR → тримайте застосунок відкритим. Якщо BF-E105, перевірте Допомога → Діагностика → P2P (WebRTC) — якщо показує недоступно, ваш браузер/мережа блокують WebRTC.

Локальний ШІ (WebLLM) не працює

Потрібен WebGPU + ~4 ГБ вільної RAM + ліцензія Pro. Перевірте Допомога → Діагностика → WebGPU/WebLLM. Якщо BF-E106: оновіть Chrome/Edge до останньої версії, увімкніть chrome://flags/#enable-unsafe-webgpu або перейдіть на Ollama (будь-яка модель, що працює локально — API-ключ також не потрібен).

Повільний пошук або імпорт

Перший імпорт будує вектори HNSW — важко для CPU. Тримайте вкладку відкритою. Для 10k+ закладок використайте Налаштування → Розширені → Примусове переоброблення. Якщо проблема лишається, у Скопіювати діагностику показано vectorIndexLoad і затримку запиту.

Коди помилок BF-E* — скопіюйте код, перейдіть до виправлення

Кожна критична помилка показує код на кшталт BF-E101. Натисніть код у застосунку або шукайте його тут.

КодЗначенняВиправлення
BF-E101Пароль сховища забуто / потрібна фраза відновленняМи не можемо відновити паролі. При створенні сховища ми один раз показуємо 24-словну фразу — запишіть її на папері. Використайте її для скидання. Без фрази сховище невідновне. Жоден запит не відновить його.
BF-E102Сховище замкнене / неправильний парольВведіть пароль точно. Після 5 невдач зачекайте 60 с. Якщо ви нещодавно змінили пароль, спробуйте попередній — ротація зберігає останню сіль для відкату.
BF-E103Перевищено квоту сховищаПерейдіть до Налаштування → Сховище: Стиснути БД + Очистити кеш ШІ. За потреби експортуйте резервну копію .bmf. Див. Усунення неполадок §Сховище.
BF-E104IndexedDB заблоковано / приватний переглядIndexedDB заблоковано в приватному/інкогніто режимі або політикою сховища. Використайте звичайне вікно. Перевірте Допомога → Діагностика → Сховище.

BF-E107Імпорт резервної копії не вдався (неправильний пароль / пошкоджений файл)Для .bmf (зашифрованого) потрібен пароль експорту, а не пароль сховища. Для JSON переконайтеся, що файл не було обрізано.

BF-E202Досягнуто безкоштовного ліміту (2 500 закладок)Безкоштовно — 2 500. Видаліть або оновіться до Pro Lifetime v1 для необмеженого. Експорт завжди доступний.

Порада підтримки: натиснувши Скопіювати діагностику у помилці, ви копіюєте код + контекст одним кліком — вставте у вашу GitHub Discussion або лист.

Скопіюйте редаковану діагностику — що ви вставляєте в підтримку

У застосунку: Налаштування → Розширені (або Допомога → Діагностика) → Скопіювати діагностику. Виглядає так — без вмісту сховища, без URL, без запитів:

BookmarkForge v1.0.0 | Chrome 126 | Vault: 847 bookmarks, 12 docs Storage: 42% (IndexedDB OK) | Last backup: 2 days ago (.bmf encrypted) P2P: not connected | Sync: never | Local AI: WebLLM not loaded Errors: 0 last 7d | BF-E: none | Build: a1b2c3d

Що містить: версія застосунку, браузер, кількості (закладки/документи/вектори), % сховища + квота, статус P2P, статус ШІ, кількість помилок і останній код BF-E, хеш збірки. Використовує солений хеш IP — ми ніколи не зберігаємо IP. Див. Конфіденційність §3/§6.

Якщо ви не можете відкрити застосунок: додайте браузер + ОС + кроки відтворення + код BF-E* на екрані. Цього достатньо для 90% запитів.
