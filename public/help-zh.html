故障排查——30 秒解决大部分问题

保险库已锁定 / 密码错误

密码区分大小写和空格。若你换过键盘布局（例如 AZERTY→QWERTY），请慢慢重新输入。连续 5 次解锁失败后，等待 1 分钟。如果密码丢失，请使用创建保险库时显示过的24 词恢复短语（BF-E101）。没有它就无法恢复——这是设计使然，我们没有后门。

浏览器存储已满

IndexedDB 配额按浏览器计算（通常为磁盘的 60–80%）。写满时保存会失败并报 BF-E103。解决：设置 → 存储 → 压缩数据库，然后 清除 AI 缓存。或者 导出备份 (.bmf) → 删除旧向量。查看诊断信息中的存储占用百分比——超过 80% 时我们会显示提示横幅。

P2P 同步连不上

两台设备必须同时在线且已解锁（WebRTC）。默认没有 TURN 中继——部分企业网络会阻断 P2P。试试：两台设备连同一个 Wi-Fi → 扫码配对 → 保持应用打开。如果报 BF-E105，测试 帮助 → 诊断 → P2P (WebRTC)——若显示不可用，说明浏览器或网络阻断了 WebRTC。

本地 AI（WebLLM）无法运行

需要 WebGPU + 约 4 GB 空闲内存 + Pro 许可证。检查 帮助 → 诊断 → WebGPU/WebLLM。如果报 BF-E106：将 Chrome/Edge 更新到最新版，启用 chrome://flags/#enable-unsafe-webgpu，或改用 Ollama（任何你本地运行的模型——同样不需要 API 密钥）。

搜索或导入缓慢

首次导入会构建 HNSW 向量——吃 CPU。请保持标签页打开。书签达到 10k+ 时使用 设置 → 高级 → 强制重新处理。若问题持续，复制诊断信息会显示 vectorIndexLoad 与查询延迟。

错误代码 BF-E*——复制代码，直达解决方案

每个严重错误都会显示类似 BF-E101 的代码。在应用里点击该代码，或在这里搜索。

代码含义解决方法
BF-E101忘记保险库密码 / 需要助记短语我们无法恢复密码。创建保险库时我们会显示一次24 词短语——请写在纸上。用它来重置。没有短语 = 保险库无法恢复。提交工单也救不回来。
BF-E102保险库已锁定 / 密码错误请原样重新输入密码。5 次失败后等待 60 秒。若你最近改过密码，可试上一个——轮换会保留最后的盐值以便回滚。
BF-E103存储配额已超前往 设置 → 存储：压缩数据库 + 清除 AI 缓存。需要时导出 .bmf 备份。参见故障排查 §存储。
BF-E104IndexedDB 被阻止 / 隐私浏览隐私/无痕模式或存储策略会阻止 IndexedDB。请用普通窗口。检查 帮助 → 诊断 → 存储。
BF-E105P2P / WebRTC 不可用浏览器或网络阻断了 WebRTC。换一个浏览器/网络、关闭严格防火墙，或改用导出/导入代替实时同步。
BF-E106本地 AI（WebLLM）无法在此设备运行需要 WebGPU + shader-f16 + 4 GB 内存 + Pro。更新浏览器，或改用 Ollama / 云端提供商（使用你自己的密钥）。
BF-E107备份导入失败（密码错误 / 文件损坏）对于 .bmf（加密）需要的是导出密码，不是保险库密码。对于 JSON，确认文件未被截断。
BF-E201Pro 授权无效 / 过期校验检查 设置 → Pro：重新输入密钥。离线校验有缓存；重新联网一次即可通过 Whop 复核。
BF-E202已达免费上限（2,500 个书签）免费版上限是 2,500。删除一些，或升级到 Pro 终身版 v1 以获得无限数量。导出始终可用。

包含内容：应用版本、浏览器、计数（书签/文档/向量）、存储占用百分比与配额、P2P 状态、AI 状态、错误计数与最近的 BF-E 代码、构建哈希。使用加盐的 IP 哈希——我们从不存储 IP。参见隐私 §3/§6。
