Pocket ditutup pada 8 Juli 2025.. BookmarkForge tetap menjaga kebiasaan baca-nanti — dengan setiap artikel, catatan dan sorotan disimpan terenkripsi di perangkat Anda.

Catatan ala Notion di Setiap Artikel

Tanpa Pelacakan, Tanpa Iklan

Pertanyaan Umum

Apakah tier Gratis benar-benar gratis selamanya?

Ya. Tanpa masa percobaan, tanpa langganan. Tier gratis mencakup 500 bookmark, pencarian teks lengkap & semantik, graf pengetahuan, dan AI dengan kunci API Anda sendiri (Anda membayar penyedia).

Apa arti "Lifetime v1" untuk Pro?

Bayar sekali, miliki v1 selamanya. Termasuk semua pembaruan v1.x (perbaikan bug + fitur kecil) selamanya dan 12 bulan pembaruan fitur dari pembelian. Pembaruan keamanan selamanya. Setelah bulan ke-13 Anda tetap memakai v1 yang berfungsi, hanya tanpa fitur baru. Versi mayor mendatang (v2, v3) adalah produk terpisah: $89 untuk pelanggan baru, $35 untuk pemilik v1 (diskon 60%).

Metode pembayaran & pengembalian dana?

Via Whop: kartu kredit, PayPal, crypto. Kami tidak pernah melihat detail pembayaran Anda. Pengembalian dana 30 hari — hubungi bookmarkforge@proton.me.

Dukungan — seberapa cepat Anda menjawab?

Free: Community help via Help Center + GitHub Discussions (best effort). Pro: email 48h business days. Vault is encrypted — we cannot see your data, so we never ask for your password or recovery phrase. See Support SLA.

Bagaimana jika saya lupa kata sandi vault?

We cannot recover it. When you create a vault we show 24-word recovery phrase once — write it on paper. Without it, no one (including us) can open the vault. See BF-E101.

Apa yang terjadi pada data saya jika saya berhenti menggunakannya?

Data Anda tetap di perangkat Anda. Anda dapat mengekspor semuanya kapan saja ke Markdown, JSON, CSV, atau PDF. Tanpa kunci, tanpa sandera.

Apakah data saya benar-benar privat?

Sangat privat. Semuanya dienkripsi di perangkat Anda dengan kunci yang hanya Anda miliki. Kami tidak pernah melihat bookmark, catatan, atau kata sandi Anda. Bahkan kami tidak dapat membaca data Anda.

Bisakah saya menggunakannya di ponsel saya?

Ya! BookmarkForge bekerja di perangkat apa pun dengan browser web. Tingkat gratis bekerja di perangkat tidak terbatas (masing-masing memiliki vault sendiri). Pro menyinkronkan hingga 5 perangkat.
